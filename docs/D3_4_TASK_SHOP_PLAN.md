# D3-4积分商店与任务闭环整理

日期：2026-11-03。用户要求在D3-3收尾后整理下一阶段内容。本稿为实施建议与待办清单，**不表示已授权开始D3-4代码实现**，也不新增任务目标、前置、商品或数值。沿用主项目main串行工作；开发者学习问答／练习继续暂停，正常功能验证保留。

规则入口：[主规则](../GAMEPLAY_DESIGN.md)、[D3-0第6～8节](DEMO3_D3_0_RULES.md#6-任务式永久解锁与前六项引导)、[任务树15节点清单](DEMO3_TASK_TREE_INVENTORY.md)。游戏内新手教程与开发者学习验收是不同事项，不因后者暂停而删减教程。

## 阶段目标

从当前档大厅进入积分商店，查看已开放任务的目标、试用物资、永久奖励与资格价格；确认购买后扣积分并保存资格。玩家在开局前选择最多一个主线与一个支线，手动开局；挑战达标经正式结算永久开放对应内容，并在后续新局、普通获取池和展览馆里一致生效。失败仍可免费重试未完成的已购资格。

D3-4的完成标准必须包括至少一条正常玩家可走通的“获得积分→详情确认→购买→携带→实际挑战→正式完成→保存重启→下局生效”链，不能只做商店外观或用开发档直接授予解锁冒充完成。D3-5再进行跨系统完整连续游玩、经济节奏与性能验收，不替代本阶段自身验证。

## 必须保留的交互与规则

- 未满足前置或尚未开放的任务完全隐藏；已开放但未买资格的任务可以查看和购买，不能将“未购买”误当成锁定隐藏。
- 点击任务先看详情，确认后才扣积分；取消不扣。购买成功不自动开局，不提供普通退款／撤销资格入口。
- 资格只购买一次，已买未完成可免费重试；完成后不可再携带。不能再次扣款、重复发奖励，保存失败须恢复原余额／资格／解锁。
- 开局前最多一主线＋一支线，可不带；局内不更换、不追加、不接续。未完成支线进度不跨局，但同一局退出／恢复保留已经正式保存的进度。
- 不带主线（包括只带支线）走本档已解锁的最深常规路线，每层Boss后可结算；不额外新增8／16／24天路线选择器。
- 当局试用与永久开放分开。指定赠送铁壁／银月包不自动扩大该包普通获取资格；莉丝忒任务明确临时开放秘枢普通获取。永久奖励只影响后续新局。
- 战斗中的进度和临时达标正式到战后／确认放弃结算才提交；普通退出恢复战前须回滚未结算进度，不提前写永久完成。支线已正式完成后，本局之后失败／放弃不撤销；明确要求胜利的目标仍需胜利。
- 局内从Esc独立任务页看主／支线目标、进度和达成状态，复用现有暂停；临时达标仅轻提示“待结算”，不弹强制确认，也不新增主界面任务按钮。
- 玩家商店、事件、奖励、融合及双方自动资源都应按本局正式启用范围过滤；敌方阵容按自己的配置生成。读档不得重新抽取已确定内容。选包阈值与按英雄记忆规则沿用D3-0，不以测试全开放替代。

## 建议按顺序实施的小闭环

### 第一步：任务目录、商店与开局选择

先让大厅入口通到独立任务页，展示当前已开放目录及详情；从目录读取价格、类别、前置、目标、物资、奖励，统一校验购买与携带资格。接入确认购买、余额不足、已购免费重试、已完成不可携带及保存失败回退。复用当前菜单字体、像素素材、设置和转场。

前六项的顺序已经完整确认；后续树连线未定时不要自行铺出整棵可购买技能树。普通实现细节（控件尺寸、函数组织、稳定ID）在开工时设计，不需要反复追加核心规则问题；具体任务叙述文案与规则文本区分。

### 第二步：四天教程到纹章包的首条正式闭环

把免费教程作为新档默认主线，接入已确认1-0固定灰烬初始包、1-2铁匠赠玛格丽特及本局无限刮刀、已阅教学提示和Esc教学帮助。敌人沿用[教程初版](DEMO3_TUTORIAL_DRAFT_20261101.md)的已授权简单配置，文案待补不改变已有目标和物资。

实际通关走正常计分与选卡，并额外同档一次赠1,000积分。随后开放第二项纹章包试炼，确认花1,000购买、携带并获开局一个普通纹章包，通关八天后永久开放普通纹章包获取。再重启并开启下一局，验证普通获取及图鉴资格一致。

跳过教程单独验证：首次创建的档不等于固定槽1；已有其他档实际完成教程后，符合资格的后续新档可整项跳过。跳过标完成、开放八天与刮刀、一次赠1,000，不算通关、不发正常结算积分、不进选卡；不能用“曾跳过”继续传播实际通关资格。

### 第三步：补齐前六项引导

固定顺序：四天教程→纹章包→第二层→铁壁→第三层→银月。

资格暂价依次为免费、1,000、2,000、3,000、5,000、8,000积分；目标路线依次为四天、八天、十六天、十六天、二十四天、二十四天。此为既有采用数值，不是本轮新增价格。

第二／三层试炼使用不占装备位的临时路线凭证。铁壁试炼开局一个大包，2-1再两个；银月开局一个，2-1两个、3-1三个，均为指定大包。实际路线、敌人及事件应随对应小闭环逐步接入，不能只把天数变量改大就声称完成多层路线。

### 第四步：已有后续节点按确认程度逐项接入

已有清单合计13主线＋2首级支线，见权威节点清单；M／S编号仅为文档索引，不直接当运行时ID。

- 日期礼包两项：第2天一大包／第3天一大一小，资格暂8,000／12,000，均通关三层。任务当局试用与永久效果共用日初首次翻路径牌前发放，各包独立从合法本英雄阵营主题抽取；树前置待补，确无合法主题时如何处理仍待确认。
- 莉丝忒：资格暂10,000，试用本人通关三层，完成开放本人及秘枢；不自动开放锻金配方／千帆征册。初始五张沿用已确认角色设计。
- 纹章合成、普通五元素、万能／混沌：资格暂4,000／6,000／12,000。合成与五元素的独立目标明确暂缓；合成两组2＋2材料的具体配方待补。万能／混沌目标为通关三层，两枚各赠一枚试用。未定目标及前置不自行补成通关条件。
- 镀金＋额外半层联合任务：资格暂20,000，奖励为专属包、额外四天半层及相关特殊事件；不恢复旧独立半层15,000方案，不推定目标为三层＋四天。12随从一名起始、其余11名不重复招募；目标、节点／事件文案、卡牌审阅及前置仍待补。
- 金币／刮刀两个首级支线：资格暂6,000／4,000；本局战斗全来源产100金币／刮30个未揭晓槽；后续新局初始金币＋5／刮刀＋2。按现有献血泵、勘纹罗盘规则做任务道具，不将永久奖励直接当当局试用；罗盘每开采两资源产一刀、余数跨战斗保存。前置／事件文案后补，当前不扩建后续等级。

此步骤不是一次性开发全部节点的承诺。待定节点保持未开放，不用未授权目标或连线补齐可玩树。

### 第五步：正常解锁、调试与跨系统接线

统一永久／当局试用／本局启用三层资格查询，接到英雄、卡包、纹章与元素贴纸、刮刀、合成、路线、自动资源和特殊奖励。按英雄记忆可选包，固定阵营包和镀金包沿用各自规则，不用普通阵营“锻金配方”替代镀金委托身份。

D3-3贴纸展示读`profile.unlocks.items`中的正式单枚ID（兼容已有别名）。D3-4必须明确任务奖励到该集合的映射，并让普通获取使用同一资格；不能只授予包名后留下图鉴不显示，也不能用发现记录反推永久开放。沿用原有普通纹章／V级融合及元素批次规则，不擅自解锁未确认内容。

已设计但尚未实现的局外调试页也列入接线待办：默认关闭、仅操作明确开发档，复用F2入口，调整先暂存，“应用并保存”才提交；可改积分、任务、解锁、发现和收藏，重置需明确范围确认。不能把调试直接解锁当作正常链验收。具体开发档标识在实施时确定。

## 开工前与实施中需要区分的待办

**可直接依据现有规则推进**：前六项顺序／目标／暂价、商店详情与购买确认、主支线数量、免费重试、教程两类跳过与一次性奖励、保存与回滚、任务试用和下局奖励生效、Esc任务页。

**明确仍需用户后补或确认**：后续技能树具体前置及且／或关系，合成和普通五元素的独立目标，合成试用两组配方，镀金联合任务目标／招募节点及未审定卡效，部分正式任务名／展示段落、英雄与事件文案、日期礼包无合法主题边界。现有已定数值和目标不再重复询问。

**实施细节可自行处理**：任务定义结构与稳定ID、节点／脚本划分、界面尺寸与动画、存档兼容字段、只读查询缓存及测试入口。确需引入依赖或升级Godot则另行说明并取得确认；本计划无需这些变更。

## 验收清单

- 同一档按真实积分购买、免费重试、实际达标、结算、重启、下局生效；余额不足、取消／重复点击、保存失败均不能重复扣款或发奖励。
- 新档、部分解锁档、开发档、连续正常游玩档分开验证；三档隔离，教程“实际完成／跳过完成”区分，旧档不虚构历史。
- 未完成本局或收藏阶段不能绕过大厅路由购买；已完成不能重复携带，主支线选择与恢复不丢失，局内不能更换。
- 战中临时达标、战后／放弃提交、中断回战前回滚、跨战斗余数、任务物资重试重发都与现有事务一致。
- 临时试用不提前永久解锁图鉴分类；实际获得仍按既有条件记录并正式提交发现，不能因未永久解锁而丢弃。正常永久完成后，下局普通获取、贴纸图鉴和卡包分类一致；资源预览仍不增加发现。
- 720p／2K实际点击、详情长文滚动、Esc暂停／返回、轻提示和页面清理；每步做针对性测试，不默认启动全量套件。
- 测试档仅写临时目录；Godot串行，每个进程显式`--log-file /private/tmp/project-card-<用途>.log`。

建议下一次授权先覆盖第一、二步，交付“教程→1,000积分→纹章包试炼→正常解锁”的真实闭环，再依次扩展。尚未实施的后续项在阶段报告中保持列明，不将第一条闭环等同于整个D3-4完成。
