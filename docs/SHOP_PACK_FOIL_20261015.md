# 商店包装倾斜与统一烫金

## 从鼠标到画面

商店卡包和贴纸包沿用原商品的固定矩形命中。指向目标包时，包图抬起，并将鼠标在原位置中的坐标归一化到 `-1～1`；价格不参与抬起或倾斜。`InspectionCardSurface` 平滑追踪这个目标，将已合成的包装当成一个平面做透视。离开后目标回到零，平滑回正后停止商品的逐帧跟随。所有可检视商品统一建立倾斜表面，单卡用透明边距保留数值角标，包装保持原生尺寸。明暗单卡同样随鼠标位置倾斜，鼠标静止时姿态稳定；刮刀与撕卡服务不连接悬停动画信号，图标保持静止。

纹章包沿用上下封皮各自的金色遮罩。其他卡包只把中央图案的三档金色映射为 `#c09852`，再使用与纹章包一致的光带；深色描边、蓝色包装、银饰和白字保持原色。三种主题的大小包共六张源图已核对：这三色只出现在中央图案内。以后换美术时须重新核对；若其他材质也使用相同色值，应增加独立材质遮罩。

右键放大和购买开包沿用同一套包装材质。卡包金光在最终透视取样后计算，即使撕包内部只缓存一次原图，反光仍会随鼠标移动，并按实际绘制像素计算。贴纸包的分层金光在商店用2倍合成精度，放大翻皮继续用4倍精度；素材保留最近邻取样。

## 关键文件与参数

- `scripts/ui/shop_offer_view.gd`：`_hover_surface` 保存单卡／包装共用的展示表面，`_hovered` 表示固定商品区域当前是否选中。`_process()` 把鼠标位置换算成目标倾斜方向；`HOVER_LIFT` 调节上抬距离，`PACK_RENDER_SCALE` 调节商店贴纸包的动态采样精度。
- `scripts/ui/inspection_card_surface.gd`：`update_pointer_force()` 供商店和放大检视共用平滑逻辑；`TILT` 控制最大倾角，`FOLLOW_SPEED` 控制响应快慢。`force` 是当前平滑后的倾斜方向。
- `scripts/main.gd`：创建包装商品时启用新的展示方式；进入卡包检视时开启 `use_pack_foil` 并关闭整面 `use_flash`。买包、保存、抽卡仍走原交易流程。
- `shaders/pixel_gold_foil.gdshaderinc`：两种包装共用的金色与光带公式。`PACK_GOLD` 是基础金色；基础暗度0.77、光带频率14、锐度10和亮部颜色决定烫金质感。
- `shaders/card_preview_3d.gdshader`：`use_pack_foil` 仅供包装开启，`pack_foil_strength` 控制亮度；普通卡牌及抽出的卡牌不自动应用这个金色映射。
- `shaders/sticker_pack_foil.gdshader`：封皮翻折与单一金色遮罩保持原流程，金光公式改为引用共用文件。

## 三个需要理解的 Godot 写法

`SubViewport` 是一张离屏画布：先把多层包装画在里面，外层 `TextureRect` 再把结果当成一张图倾斜。商店合成放在 `_ready()` 中，因为画布入树后才具备完整渲染上下文；零边距使逻辑尺寸仍等于原包装大小。

`get_local_mouse_position()` 已包含父级平移与缩放的逆变换。商店忽略视觉上抬后的偏移，避免包图移动又反过来改变命中与倾斜目标；叠包仍由 `ShopPackStackView` 的固定区域选中。

`ShopPackStackView` 在悬停期间使用 `gui_get_hovered_control()` 判断当前GUI命中节点，并统一更新选中包。检视暗幕接管输入后会清除叠包的悬停归属；商品不再只依赖一次 `mouse_exited` 信号来回正，从而避免关闭检视、切换商品后留下多个倾斜包。

`.gdshaderinc` 是 shader 共用代码文件，通过 `#include` 引用，避免纹章包和主题包各维护一份渐渐不同的反光公式。色值比较只决定哪些源像素属于金色，光带则使用连续UV计算，所以像素图清晰而动态光影不必按素材像素分块。

## 验证入口

`tests/shop_pack_foil_hover_test.gd` 逐一检查六张包装的真实GPU输出：金色随鼠标变化、其他颜色与透明度不变、三档金色统一、4倍光带具有像素内渐变；再用真实商店输入检查倾斜方向、回正、固定价格与叠包命中、4倍检视，以及金币／随机流不变。传入 `-- 2k` 可验证2K窗口。

相关回归：`tests/card_pack_native_size_test.gd` 检查原生尺寸、定向包、真实购买、撕包和收卡；`tests/sticker_pack_opening_test.gd` 检查封皮翻折、金色范围、抽纸和交易一致性；`tests/d2_7_pack_surface_test.gd` 检查共享检视表面与叠包购买。

2026-10-15使用项目现有Godot 4.7.2、Compatibility和Apple M4实际GPU窗口验证。新增悬停测试在720p／2K通过；包装原生尺寸、贴纸包2K翻皮、共享检视表面回归均为零失败。原生窗口测试逐个运行，每次显式指定 `/private/tmp/project-card-<用途>.log`。

2026-10-15悬停精简：删除自动轻晃的振幅、速度、计时与旋转分支，同时移除重复的商品类型开关。明暗单卡、卡包和贴纸包共用同一鼠标跟随；单卡不应用包装金色材质。放大检视使用外层表面的位置，暗单轮播和属性沿用内层真实卡面，打开／返回时补偿透明边距以保持原位。

单卡的 `SubViewport`（离屏画布）保留四周透明边距以容纳数值角标，商品占位与价格位置仍按原卡尺寸计算。`InspectionCardSurface.card` 引用内层卡面，外层 `Control` 提供位置与可见性；主流程据此分别处理暗单轮播和放大／回退，避免把合成后的表面误当成卡牌数据节点。
