# 局内卡牌外观出售加价（2026-10-27）

## 功能流程

卡牌放入商店服务槽后，服务页读取真实OwnedCard的卡面与卡图，调用原卖价入口报价。先计算原有品级、法术剩余耐久、纹章／元素贴纸、已刮开符文、伤势和最低卖价，再追加两维外观金币；外观部分不按法术耐久折算。

| 卡面 | 额外金币 |
| --- | --- |
| 普通 | 0 |
| 银闪 | 1 |
| 金闪 | 2 |
| 彩闪 | 4 |
| 法线闪 | 8 |
| 碎闪 | 8 |

| 卡图 | 额外金币 |
| --- | --- |
| 普通 | 0 |
| 全息 | 8 |
| 超框 | 8 |

两维相加最高＋16。无其他修正的I级碎闪＋超框售17金币，普通＋普通售1金币。V级法术剩2次的原卖价为ceil(16×2／5)＝7，碎闪＋超框最终售23金币。随从、物品、法术、资源四类共用此规则。

点击出售会重新检查当前报价，再沿原交易增加金币、移除卡牌并保存。存档失败恢复卡牌与金币；成功后单笔撤销按实际成交金币反向结算，并恢复原实例及两维外观。旧档缺少外观字段时沿既有读取规则变为普通，不重抽。局后罕贵度积分、结算、解锁不在此次实现范围。

## 数据与脚本

- `data/demo2/ordinary_shop_config.json`的`card_sale.surface_bonuses`与`card_sale.art_bonuses`是唯一加价数值表。键复用外观的稳定字符串，不把枚举序号当JSON键。
- `scripts/main.gd`的`_shop_card_sale_price()`保留原计算顺序，仅在最低卖价处理后追加两项。`ShopBoardView`的服务页金额、按钮及`_execute_shop_sale()`继续调用这个入口，无第二份定价。
- `OwnedCard.surface_finish`、`art_finish`仍是单卡权威数据；`CardAppearance.SURFACE_KEYS`、`ART_KEYS`负责枚举到配置键的映射。不新增出售专用外观字段，不把价格缓存到卡牌。
- 原`_capture_shop_card_transaction()`、`_remember_shop_card_service()`和`_undo_shop_card_service()`已包含完整外观快照与实际`gold_delta`，此次直接复用。`RunSaveService`继续保存既有外观键，无需更改存档版本。

## 初学者需要理解的写法

`maxi(price, minimum_price)`先应用旧卖价下限，再执行`+ surface_bonus + art_bonus`。若把外观加价提前放入旧价格，会被伤势抵扣或被法术耐久折算，违反本次规则。

`Dictionary.get(key, default)`读取配置；先用枚举查稳定键，再按该键读取金币。调整数值只改JSON这一处，展示与交易随之使用同一结果。出售函数保留`expected_value`复核，避免过时报价销毁卡牌。

撤销里的`gold_delta`记录已经成交的金额，返还卡牌时扣回该金额，不再次抽外观或重新报价；完整快照按`instance_id`恢复原卡身份，因此同名卡不会互换工艺或贴纸。

## 经济核算

目前普通大包18金币、5张，品级权重I／II／III／IV＝75／20／4／1，若前4张均没有II以上，最后一张在II以上候选中抽取；空品级重归一化、IV持有排除及同名3张后降权仍由原生成器执行。本次不改包价、概率、保底、刷新费或任何其他经济规则。

单张外观平均加价为1.75＋0.8＝2.55金币，小包3张共7.65金币，大包5张共12.75金币。完整I～IV候选下，未触发保底的单张品级卖价期望为1.39，保底抽取为2.56；普通大包原品级卖价期望约7.32，因此含外观约20.07金币，比18金币包价高约2.07金币。

2026-10-27补充小包与大包对照，以下以三类当前主题均有完整I～IV候选、没有因持有而排除品级为基线；开出立即卖，不刮符文、不加贴纸、不计伴随奖励及刷新费：

| 包型 | 购买价格／张数 | 平均出售收入 | 平均净收益 |
| --- | --- | --- | --- |
| 小包 | 12金币／3张 | 11.82金币 | −0.18金币 |
| 大包 | 18金币／5张 | 约20.07金币 | 约＋2.07金币 |

小包没有II级保底，计算为3×(1.39＋2.55)＝11.82。大包在前4张全为I级时才替换最后一抽，其概率为0.75⁴；故品级期望为5×1.39＋0.75⁴×(2.56−1.39)＝7.3201953125，再加12.75为20.0701953125。III以下候选数量足够，不会在5张内耗尽；每主题3张IV同包全抽完后的极小概率重归一化影响不改变这里两位小数。

本次另以正式生成器对三主题、小／大两种包各抽10000包，共60000包，读取真实实例卖价；脚本和JSON核算输出保存在`/private/tmp/project-card-pack-resale-calculation.gd`及`/private/tmp/project-card-pack-resale-calculation.json`，日志为`/private/tmp/project-card-pack-resale-calculation.log`。各主题小包抽样原品级卖价4.1685～4.1755，接近理论4.17；大包原品级抽样7.2791～7.3403，接近理论7.3202。外观抽样同样有波动，以上长期期望以概率公式为准。定向小包若行动候选缺少某品级、或实际持有使某品级全部排除，需按当时合法卡池重新归一化，不套用此完整候选基线。

使用正式`draw_card_pack()`及`OwnedCardCollection.create_card(..., true)`，各主题独立抽样2000个大包；每包以空持有列表开始，包内去重、同名降权和II以上保底按实际规则执行，卡面卡图按原随机方法生成。仅计算这5张新卡直接出售，不刮符文、不加贴纸，不计伴随奖励：

| 主题包 | 平均出售／扣包价后净额 | 出售收入高于18的比例 |
| --- | --- | --- |
| ash_ledger | 20.1445／＋2.1445金币 | 53.90% |
| silvermoon_chapter | 20.0195／＋2.0195金币 | 52.20% |

这是买包后立即转卖的正期望基线，不保证每包盈利，也不等同无限无成本循环。持有IV会改变候选；商品限购，后续刷新费用按原规则递增，以上净额只扣包价，不扣刷新等额外成本。保留用户已确认加价，经济影响留待后续平衡决定。
