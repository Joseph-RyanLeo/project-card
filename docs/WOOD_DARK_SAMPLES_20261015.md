# 木穿刺与暗连击原画样板

## 当前木穿刺实现（2026-10-16）

此前提取主刺再沿路径移动的版本误读了原图，已删除。用户明确：原图中间两段留白各代表一张卡牌的长度。当前恢复每个角度的全部16张原帧，保留原始颜色、刺头、三个显现位置、残影与碎屑；每次真实穿刺仍只选择三个角度中的一个，不将演示的三列同时当成三次命中。

原图两张卡牌位于纵向114—250、274—410，各136像素，中心距160，卡牌之间空隙24像素。当前按真实卡高对齐两段卡牌空间，只单独重映射两卡之间的排间空隙；不再把450像素画布整体压缩到两排中心距，也不额外平移主刺。默认宽度参数70表示原图横向比例，纵向始终按实际卡高组织。

游戏中 Esc → 攻击特效调试器 → 木·穿刺 → 应用朋友原画样板。预览显示两张真实卡牌，便于检查下缘起刺、穿过两卡、上缘露出长刺以及分段残影。已有草稿与保存配置沿用，命中节奏参数保留；保存并应用后用于正式战斗。

## 1. 输入到画面

正式木元素事件→Main／战斗实验室提供两卡中心、真实卡高与命中延迟→共用渲染器创建原画节点→Shader只适配排间空隙→同一个Tween切换完整原帧并触发原有命中回调→残影结束后释放。

动画帧2对应穿过上方卡牌、首次在上缘显现，与`progress=1`的逻辑命中对齐；命中前两帧按既有命中时刻对齐，命中后的2—15帧各保持原GIF的50毫秒。渲染节点可延长显示寿命，伤害时刻不延后；调试器按实际显示寿命安排下一轮。没有修改目标、倍率、命中延迟或伤害次数。原画已含命中表现，继续跳过旧菱形冲击。

## 2. 核心文件与数据

- `assets/effects/hand_drawn/source/wood_pierce.gif`：原始563×450、16帧、每帧50毫秒GIF，与用户本次附件SHA-256一致。
- `tools/prepare_element_sample_atlases.py`：按三个角度裁列，每格160×450。只将纯黑底透明化，不再裁主刺或重排像素；暗图集沿用原逻辑。
- `scripts/battle/battle_element_sample_visual.gd`：`WOOD_ORIGINS`保存原图下方卡牌的中心锚点；`card_scale`匹配真实卡高；`extra_gap`只增减排间空隙。`configure()`建立几何与材质，`update_visual()`按实际已播放时间切换完整帧，`WOOD_FRAME_SECONDS`保存原图50毫秒帧间隔。
- `shaders/battle_wood_card_spacing.gdshader`：`card_scale`、`row_gap`与`canvas_height`控制纵向映射。250和274是原图两卡间隙的上下边界；这一区间之外保留原比例，RGB直接读取原图。
- `scripts/battle/battle_attack_trail_renderer.gd`：新增实际卡高参数，其余样式忽略它；继续统一管理命中、暂停、倍速和释放。
- `scripts/main.gd`、`scripts/tools/battle_lab.gd`：把真实卡位高度转换到特效层后传入。
- `scripts/tools/attack_effect_lab.gd`：木模式显示两张原比例卡牌；火／暗仍使用原有两倍单卡预览。

## 3. Godot / GDScript 说明

`Sprite2D.hframes=16`、`vframes=3`将图集分为角度行与帧列。`frame=角度×16＋帧号`只选择一格原画，不代表多次伤害。最近邻过滤保留原始像素边缘。

Shader的UV是取图坐标。本次只把实际排间空隙反算回原图24像素的小区间；两段各136像素的卡牌空间各自按真实卡高缩放，首尾原画也保持同一比例。`basis_xform()`只转换尺寸向量，不加位置偏移，因此可把真实卡高正确交给特效层。

原图本身已经表现了穿刺的显现过程，所以Sprite固定在两卡对应位置，只切帧。这样不会再次变成一枚沿路径移动的小刺。

## 暗连击

暗继续使用每击四帧原画，白闪→紫色斩痕→淡出。每次事件以原目标为中心独立随机旋转，三暗一斩、五暗三斩仍由控制器决定；预览只演示三次独立事件。未改动本轮暗效果。

## 验证方式

`wood_reference_fidelity_test.gd`在Godot透明SubViewport中实际绘制全部48格，在原比例下与原图集逐像素比较；再将排间距增加100像素，检查两段136像素卡牌区域仍逐像素保持原样。Godot导入时会向透明像素扩散边色，测试先预乘Alpha清掉不可见RGB，再做严格对照，不放宽可见像素要求。

`wood_dark_samples_test.gd`继续覆盖真实预设按钮、三种变速命中、暂停／三倍速、命中一次、节点释放、随机角度版本、JSON往返以及正式Main中的三木、三暗、五暗。

额外帧节奏检查在三种速度变体下逐50毫秒推进真实Tween，确认命中时进入第2帧，此后2—15帧全部按序保留，长刺不会因命中后的剩余时间过短而被跳过。

最终验证：原画保真与帧时序14项、真实木暗119项、共用视觉24项、水火44项，共201项通过；无脚本或Shader错误。另逐像素核对透明图集48格与源GIF一致。实际双卡预览为 `docs/previews/wood_reference_20261016/wood-two-cards.gif`，仅裁切组合原生绘制帧。
