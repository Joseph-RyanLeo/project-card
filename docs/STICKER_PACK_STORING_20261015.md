# 贴纸包：随机旋转、逐枚剥离和入箱

## 玩家操作与演出流程

购买仍先完成五枚贴纸入库、金币扣除及存档，再开始演出。上封皮翻起后抽出整张底纸，五枚图案分别以±45°内的不同角度摆在白点中心。普通点击保留两个检视停留点：第一次点击整张贴纸开始剥离；五枚全部放入工具箱后，空底纸回中间供鼠标倾斜检视，再点击飞走。

剥离过程自动连续播放：底纸先收平，五枚原图标移到暗幕上方，除图标外的画面额外压暗；依次向上揭起、旋转转正，在中央并排。随后原工具箱从屏幕左侧滑入，只露出右半的4列×7行纹章槽，队列和底纸同时右移100逻辑像素。五枚按队列从左到右飞入已经保存的各自槽位，每次落槽工具箱轻震。最后工具箱收回、额外暗幕消失、空底纸居中。

演出沿用 `AnimationClickSpeed` 的连续左键点击判定，最高8倍。连点后持续加速，后续Tween继承倍率，并自动跨过“整张贴纸”和“空底纸”两个停留点，播完后回商店。手动拖动翻皮不计作连续点击，避免分段拖拽误触自动开包。

## 数据与脚本职责

- `scripts/main.gd`：`_buy_shop_sticker_pack()` 在原事务成功后返回五个真实实例ID；失败仍回滚并不播放。`_open_shop_pack_inspection()` 将ID、已有工具箱和包装画布交给演出。实例ID区分同名贴纸，落点从真实工具箱读取，不再按图标名称猜测。
- `scripts/ui/sticker_pack_art.gd`：`STICKER_ROTATION_LIMIT` 控制最大随机角度。局部 `RandomNumberGenerator` 用已确定内容和底纸样式播种，只产生外观角度，不改变商店玩法随机流。`pivot_offset` 放在图标中心，保证旋转后仍围绕白点。
- `scripts/ui/sticker_pack_opening.gd`：`phase` 是当前演出阶段；`_sticker_ids` 对应本包五个真实实例；`_flying` 是从原底纸移出的图标；`stored_count` 表示已播放完成的入槽数量；`_click_speed` 保存加速倍率，`_auto_advance` 表示自动跨过后续停留点。`_library_layout` 只保存暂时借用工具箱前的父节点、位置、倍率和交互状态，用于结束或强制关闭时恢复。
- `scripts/ui/emblem_library_view.gd`：`set_hidden_item_ids()` 是演出共用的显示接口。贴纸仍真实占据已保存的格位，只在对应飞行图标落下时显示库存图标；原纹章合成也通过这个接口控制临时隐藏。

人工可调参数集中在开包控制器顶部：`STICKER_ROW_STEP` 控制排列间距，`STICKER_LIFT` 和 `STICKER_LIFT_ANGLE` 控制剥离动作，`BACKDROP_ALPHA` 控制暗幕，`CONTENT_SHIFT` 控制向右让位，`STORE_SECONDS` 控制入槽速度，`TOOLBOX_SHAKE` 控制落槽震动。每项声明旁均有中文说明。

## Godot写法说明

`reparent()` 是移动现有节点到另一个父节点。这次从离屏底纸画布移出原图标，让它们能独立飞行；移出前用检视的正向投影求屏幕中心，再转换成演出层坐标，避免窗口倍率引起跳位。先将底纸收平，再移出图标，保持透视变化连续。整张底纸也提高到4倍采样，防止随机旋转边缘先在1倍画布中变粗再被放大。

`Tween.parallel()` 让位移与旋转同时发生，后续普通Tween步骤按顺序播放。各阶段通过完成回调自动接续，`_start_animation()` 给新Tween应用当前加速倍率，所以连点不会只加速当前一小段。

入箱不是第二次发奖励。图标先隐藏、落槽后显示，库存数组和坐标始终保持交易完成时的状态；`get_item_canvas_rect()` 返回包含2×2元素贴纸尺寸的真实图标矩形，普通纹章、同名纹章与元素贴纸因此都能准确落位。

## 工具箱独立展开、自动整理与临时区域（2026-10-15修订）

本节取代此前“按隐藏内容预判空间并禁用购买”的实现。现在购买只检查资金、内容有效性及已有唯一性约束；空间不足仍接收全部五枚，事务成功保存后再播放。默认按玩家原布局试放；本包含元素、原空格至少8且试放失败时自动整理。排序为元素优先、稀有度由高到低、同名相邻。采用副本逐次完整装箱，旧格内实例全部优先保留，再选择可容纳的新贴纸，不把旧实例挤出。

`EmblemStickerInventory.receive()`负责整批接收，`storage="drop"`表示同一实例处于临时区域；`drop_position`保存两个原生逻辑坐标，格内仍用`grid_x/grid_y`。掉落不占格、可以重叠。`move()`使掉落回包，`move_to_drop()`释放格位并保存自由位置，`discard_dropped()`只销毁临时实例。无效输入不修改真实库存。视图从定义读取稀有度交给模型，模型不依赖UI节点。

收藏页直接点击原工具箱；各界面均不再创建左下角工具箱缩略入口，包含商店、事件和结算。Main借用同一个`EmblemLibraryView`，从原工具箱位置在0.28秒内平滑移动、放大到左侧4倍检视位置，背景同步压暗；动画结束后启用拖拽。点击收起、背景、右键或Esc时，从当前状态在同样0.28秒内平滑缩小、返回原位置，背景同步变亮，动画完成后才恢复原父节点和局部布局。展开中途收起也直接从当前状态返回；重复关闭不重启动画。切换视角、开始战斗、进入卡牌检视或退出事件等流程切换会终止补间并先完成节点归位，防止同一工具箱被新界面重复借用。不创建第二份库存。`EmblemLibraryEntry`沿用指示物的抬起、下落时长，临时贴纸悬停只抬升1个原生像素（4倍检视时为4个逻辑像素），阴影只轻微拉开；仍使用统一的`InspectionItemDrag`抓取偏移。鼠标落在另一枚贴纸上时，目录项将落点转发到格网，临时区域因而可以互相叠放。`EMPTY_CELL_ALPHA=0.55`控制格网底色，`DROP_AREA`控制工具区下三分之一的范围。

临时贴纸按最近操作置顶：按下或开始拖动时，目录项通过`front_requested`信号通知视图；`EmblemLibraryView._drop_stack_order`只记录界面前后顺序，`move_child()`同时调整绘制和重叠点击的命中顺序。拖放完成重建目录、取消携带和其他界面刷新都保留该顺序，已经离开临时区域的实例从顺序表删除。库存数组、占格、奖励排序和存档格式不随置顶改变。点击携带继续使用现有高层携带层，原生拖拽继续使用独立4096层预览。

开包有掉落时完整露出工具箱，各飞行图标仍从`get_item_canvas_rect()`读取真实格位／临时位置。演出只显示已保存的结果，不重复入库。原战后地面奖励按钮列表及“处理完才可继续”的拦截已删除，旧存档奖励队列迁入这一份临时库存。

事件、离店与结算下一天先调用`confirm_temporary_sticker_discard()`；取消后保留并展开工具箱，确认后在对应事务中销毁临时贴纸、不退款。新增奖励导致掉落的事件保留`reward_claimed`，先停留供整理，避免同次领取立即丢弃或重复发奖。退出存档失败回滚库存。当前存档版本3保存精确格位和临时位置，只有版本2以前的旧坐标需要重排。

`Callable.bind()`把“确认后继续哪一步”的参数保存在回调中，弹窗确认后才调用；取消不执行动作。`reparent()`移动现有工具箱节点，只改变显示父层，不复制数据。

展开时先保存原父节点及局部布局，再把起点的画布变换转换到检视层坐标；因此界面缩放不会使动画起点跳位。收起时用原父节点当前的画布变换乘以保存的局部布局，求出正确返回位置。`Tween.set_parallel(true)`让位置、缩放、旋转和背景同时变化；`chain()`在展开结束后启用交互，在收起结束后调用`_finish_toolbox_inspection()`归位并移除外壳。`_toolbox_closing`阻止重复输入重启动画；流程切换通过`_close_toolbox_inspection(false)`立即完成同一清理逻辑，`kill()`停止旧补间，避免迟到位移。
