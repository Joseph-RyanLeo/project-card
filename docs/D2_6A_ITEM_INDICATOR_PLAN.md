# D2-6A 物品与指示物边界

玩法权威仍是 `GAMEPLAY_DESIGN.md`。本文只记录 D2-6A 的实现拆分，避免把三种外观相近、归属不同的对象塞进同一数据结构。

## 三类对象

| 对象 | 权威数据 | 显示与交互边界 |
|---|---|---|
| 收藏中的物品卡 | `CardData` 定义内容，`OwnedCard` 表示本局唯一实例 | 在收藏中显示完整卡面，可拖到随从单兵或小队上装备；不进入随从堆叠 |
| 小队上的装备指示物 | `SquadData` 引用同一个物品 `OwnedCard`，并保存指示物中心在小队卡面内的局部坐标 | 只是装备状态的场上显示，不是第二张卡、不占战场单元；拖离卡面后立即恢复完整装备牌 |
| 其他指示物 | 后续独立的指示物定义、实例、库存与位置数据 | 不属于 `CardData`、`OwnedCard` 或装备位；附着小队、放置半场和部署到特殊区域由各自规则限制 |

装备和物品卡是一份实例的两种表现。装备时不能复制 `OwnedCard`，卸下时也不创建新实例。太阳、月亮、星星、福金、雾尼、注视与哨位不能借用装备位，因为它们的保留周期、目标位置和销毁规则彼此不同，也不具备普通物品卡的出售与卡面身份。

## 小步顺序

1. **装备归属基础（已完成）**：小队保存唯一物品实例引用；支持装备、卸下、复制快照、JSON 往返、单件堆叠保留、多件冲突返还与拆队返还。
2. **装备指示物交互（已完成）**：拖动中的完整装备牌进入可装备卡面便实时变成指示物，离开卡面便恢复完整装备牌；成功松手时指示物从当前可见位置向卡面下落6px，已装备指示物拿起时保留鼠标实际抓取偏移。指示物松在收藏或任意无效区域都会解除绑定，并从松手处动画返还收藏。
3. **装备属性与效果（已完成本阶段范围）**：行动值、生命、护甲和整数热诚已接到小队有效属性、战前卡面与战斗状态；装备 `effect_ids` 已按装备实例注册。原冷却秒数增加／减少分别改成热诚-1／+1，保留原增强削弱方向；装备卡面已换成用户提供的热诚图标，其左上角相对旧沙漏左移、上移各 1px，正负号使用用户提供的像素素材。15张演示装备仍无正式效果 ID；灰烬征册五件正式装备已接入已确认效果，其他装备不在本阶段擅自补齐。
4. **日月星指示物（已完成本阶段范围）**：独立库存、实例身份、同名限制、附着位置、战前快照与 JSON 存取已接入；太阳、月亮、星星的战斗属性、耀眼抑制、影蔽计时、星星传播及战后恢复均使用战斗副本，不改写战前持有者。独立库存暂用临时卡板标记，库存内位置可自由拖动并保存，卡板素材和最终边界待后续确认。
5. **其他指示物**：福金、雾尼、注视与哨位延期，不在本阶段伪造实现。

## 第一小步的不变量

- 每个小队当前最多引用一件物品实例。
- 非物品 `OwnedCard` 不能进入装备位。
- 两个小队堆叠后恰好只有一件装备时，新小队保留该实例。
- 两边都有装备时，新小队不保留任意一件，两件实例仍在收藏容器中，恢复为可用物品卡。
- 拆队统一解除装备引用。
- 战前快照复制和本局 JSON 存取都保留同一个装备实例 ID；损坏或重复占用的装备引用必须拒绝读取。
- 装备落点在小队数据内部相对当前最上层卡牌保存；叠卡、换顶牌或改变横向布局后，指示物保持在新顶牌的同一立绘位置。显示和存档接口仍使用小队局部坐标，由数据层统一换算。

当前指示物使用用户提供的 `30×30px` 阵营圆形底座与六类装备、五个品级图案实时合成，合成纹理与逻辑显示尺寸都保持原生 `30×30px`，不再内部扩图；静态总览图也由 `tools/generate_equipment_indicator_catalog.gd` 用同一合成函数生成。各类型图案按实际非透明像素边界在底座上居中，而非按包含不同留白的23px图集格子统一偏移。底座颜色来自卡牌或所属卡包的阵营：辉光同盟蓝、汉萨联邦红、野性兽巢绿、寻路者协会橙、迷宫紫；中央图案来自装备类型与品级。拖放时按指示物可见中心寻找小队顶牌立绘，只有携带位置与向下6px的最终位置都能完整放入立绘时才接收；最终中心为可见中心下方6px，并随小队移动、悬停上跳、目标颤动快照与拖拽快照一起变化。落点坐标也会进入战前快照和本局存档。日月星临时卡板使用独立的实例位置表，库存内自由摆放时以可见中心和原始抓取偏移计算落点；原生长按结束通知即使预览已回收，也会使用最后鼠标位置恢复抓取偏移后的可见中心。指示物静止时阴影贴近卡面，鼠标指向时图标独立上跳、阴影拉远，离开时再向下落回；刚落地时先等待鼠标离开命中范围，下一次进入才触发上跳，长按拖拽与单击携带共用该规则。本阶段尚未启用阵营战斗效果。
