# 弹道与频繁换位性能优化（2026-10-10）

## 测量与修改依据

压力探针使用正式 Main 场景、正式战斗控制器、真实银月卡牌、弹道、动画、音效和战斗诊断采集。计时子类只包装 `super` 正式调用，不替代规则或渲染。28张随从、四排各7张，夹具冷却0.5秒；每种场景预热10帧后采样240帧，手动以1/60秒推进逻辑。第二种负载每6帧额外执行4次正式换位，共160次；卡牌自身的位移监听和自动换位仍运行。生命抬高仅用于维持压力窗口，未修改正式资源。

初测的主要开销是状态查询、卡面同步、换位同步，而非弹道节点创建。没有减少弹道数量、动画帧数或诊断内容，也没有添加依赖。

## 第一层：从输入到结果

换位仍立即更新逻辑排和索引，重算位置并同步光环。显示同步先找出受影响的排，各排只捕获一次实际卡面位置；随后统一重排，再使用已有排动画事务播放。同一帧多次换位沿用最早视觉起点；跨排卡牌在 `reparent` 前捕获起点，换到排尾也保留动画。

查询属性时，空伤势和空纹章不再生成完整槽位布局、遮挡结果和临时字典。查询界面和拖放槽位的默认行为仍保留全部可见空槽。无伤势、无火符文强化来源、无符文覆盖、无纹章遮蔽时，战斗状态查询直接返回空结果；实际安装、遮蔽、放逐或符文变化仍即时读取。

布局重算末尾已同步银月光环，因此移除换位函数紧接着的第二次光环同步。已在目标索引的卡槽不再次重排；目标权重显示开关相同时不再次遍历卡面。

## 第二层：数据与脚本职责

- `main.gd` 的 `_sync_battle_formation_positions`：根据运行时状态定位卡槽，保存受影响排及卡面起点，统一提交显示重排。
- `battlefield_row.gd`：管理卡槽顺序、等待容器布局、补间动画；沿用 `_pending_layout_positions` 和现有动画事务。
- `squad_data.gd`：`get_visible_wound_slots`、`get_visible_emblem_slot_indices` 增加 `occupied_only` 参数；属性计算传 `true`，界面默认 `false`。
- `battle_squad_state.gd`：根据运行时实际状态跳过空查询，保留原来的非空处理路径。
- `silvermoon_runtime.gd`：执行规则换位；光环继续由控制器布局重算即时同步。
- `squad_view.gd`：相同目标权重显示开关不重复更新；重建卡面时继承小队当前开关。

## 第三层：GDScript写法

`Dictionary` 的排节点键用于去重：同排移动多张卡仍只安排一次事务。`merge` 合并卡面起点；已有事务只接纳尚未保存的卡槽，因此不会覆盖同帧最早起点。

`reparent` 改变真实节点归属，`await process_frame` 等待 Container 算出最终布局，再由 Tween 从之前的画布位置播放。这只延后表现，不延后规则判定。这里复用排节点现有的捕获和动画函数，因为逐卡调用原接口会重复捕获整个排，并遗漏已经位于新排尾端的跨排起点。

`Array.all(func(...))` 检查每个槽字典是否为空；空状态可提前退出昂贵的布局计算。不缓存运行时规则数据，避免伤势、纹章和遮蔽变化后的失效问题。

## 验证与性能结果

Godot 4.7.2，Apple M4，本机1280×720。实际渲染使用 OpenGL Compatibility，关闭垂直同步；无窗口使用同一正式场景。各进程串行运行，均显式指定 `/private/tmp/project-card-*.log`，测试存档仅使用临时路径。没有运行全量套件。

| 场景 | 窗口P95：修复前→后 | 无窗口P95：修复前→后 |
| --- | --- | --- |
| 弹道密集 | 44.65→30.84 ms | 38.97→19.30 ms |
| 弹道＋160次额外换位 | 57.69→40.52 ms | 51.65→26.20 ms |

实际渲染的中位帧耗时分别为25.89→16.45 ms、26.93→17.91 ms；最大帧分别为90.46→64.09 ms、119.12→71.03 ms。该极限负载仍有慢帧，不能据此承诺所有设备稳定60FPS。

无窗口前后对照两种负载的伤害时间轴、目标、数值和随机终态完全一致，弹道次数分别为524、587，第二场额外换位均160次。窗口对照使用同等压力，第二场弹道为571→586，因此约30%的窗口改善是同等负载比较，而非逐事件相同回放。额外重复采样发现换位场次偶尔有同种子目标序列差异，修复前也存在；本轮没有改写选目标或随机规则，不宣称已解决该独立问题。

- 新负载优化回归：26项，0失败；覆盖跨排尾端起点、同帧三次换位、节点和逻辑顺序、耀眼即时变化、无位移不创建事务、实际伤势/纹章及符文覆盖、重建卡面的显示开关继承。
- 银月规则：467条，0失败；银月后续回归：73条，0失败；主游戏集成：11条，0失败。
- 现有伤势与音效运行时测试：0失败。
- 疲劳回归：125项，124项通过；旧断言把 `moon_shadowed` 当作放逐并期待免疫风暴。当前 `_prepare_fatigue_events` 判定 `is_banished`；该代码不在本轮差异中，未修改旧断言。
- 原始空槽查询、实际安装状态、跨排动画起点均验证通过；实际渲染截图已检查。Godot 无窗口启动仍有既有系统证书读取提示，部分测试退出时有对象/资源回收提示；没有解析错误或运行时脚本错误。
