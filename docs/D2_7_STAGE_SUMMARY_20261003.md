## 本阶段成果

### 普通商店与实际交易

- 灰烬证册大／小卡包、明暗单卡、纹章贴纸包、无限购买刮刀和撕卡服务接入正式配置；支持商品售出、刷新、出售与继续游戏。
- 抽取遵守合法候选、空品级重分配、IV持有去重和大包II级及以上保底。明暗单卡、贴纸包及服务价格按既有确认，不因视觉修改重定价。
- 暗单仅持有公开提示生成的卡框与问号；未知信息轮播、提示信息固定。八类合法提示暂用相同权重，新增种类提示沿用非品级报价。
- 开包及隐藏商品揭晓立即保存；失败交易回滚，读档保留报价、实例、库存和随机状态，不依赖动画回调发奖励。

### 符文与刮刀公平性

- I—V级未揭晓覆盖使用正式素材；新收藏卡的底层符文默认未揭晓。
- 工具箱点击刮刀进入专用行动；悬停和经过卡面不刮。首次实际擦除每槽合法覆盖像素扣一把刀，同槽不重复扣；覆盖实际不透明区域70%时提前揭晓，退出时补完本次已付费槽。
- 未揭晓符文没有元素收益，不参与牌型或战斗派生，并保留连续组合断点。实例数据、拖影、虚影、悬停描述、检视与战斗显示一致，透明度变化不能漏出秘密。
- 旧存档保留已揭晓状态和真实实例，仅清除旧版未结算擦痕；不免费揭晓局部偷看的槽，也不重抽符文。
- 工具箱保留刮刀凹槽；拿起时原图暂隐，手持与原位显示尺寸相同，取消后飞回原位。

### 商店视觉和动画

- 桌布仅进入商店时覆盖敌方中央两排；离店恢复准备界面。资源详情、检视、Esc和F2位于商店上方。
- 商品直接点击购买、右键检视；同主题同大小卡包和贴纸包分别叠放，真实前层遮挡优先。商品位于首排，服务在独立紧凑区，没有商品滚动条。
- 商品价格及服务文字保持静止；仅目标卡图／包图抬起轻晃，刮刀和服务图片不晃。商店独立金币图片配卢恩数字，卡面正文保留原字体与普通金额符号。
- 开店下落越过后回弹、关店向上收起；四类商品检视从原位置放大到基础4倍，取消缩回。包装沿用卡牌光栅与倾斜。
- 成功买包先放大，再暂用战斗死亡噪声溶解；卡牌逐张展示的完整开包后半段尚未制作。
- 购买及购买失败不重建未变化的商品节点，暗单继续原轮播；售出后的图片与价格平滑补位。

- 建立Windows命令／PowerShell采集工具与分析脚本，采集帧时间、阶段、翻页、拖动、开战、结果页和硬件信息。使用正常重新导出的EXE及 `Run-Diagnostics.cmd`，撤掉依赖不受支持的 `--main-pack` 外置补丁启动方式。

## 三层实现说明

1. **输入到结果**：进入商店生成或恢复报价 → 点击交给交易函数校验候选和余额 → 一次提交金币、拥有实例及保存 → 陈列删除售出节点并补位／播放开包；检视仅展示。刮刀点击进入模式 → 首次合法像素付款 → 达阈值或退出揭晓 → 数据和战斗属性同步。
2. **主要入口及数据**：`scenes/Main.tscn`、`scenes/ui/ShopCardView.tscn` 与 `scripts/main.gd` 连接界面和流程；`OrdinaryShopService` 与 `data/demo2/ordinary_shop_config.json` 保存报价、概率和随机流；`run_reward_state.gold` 保存余额，`OwnedCardCollection` 保存真实实例，`OwnedCard` 保存符文与揭晓标记；`RunSaveService` 编解码本局。`ShopOfferView`／`ShopPackStackView` 管理陈列输入和补位，`ShopCardView` 管理脱敏轮播，`InspectionCardSurface` 管理合成画布和倾斜。
3. **Godot写法与原因**：`add_child` 触发首次 `_ready`，先赋数据可减少重复初始化；`remove_child` 只移动节点，`queue_free` 才销毁，翻页复用必须区分两者。信号把显示输入交给Main，显示脚本不自行扣款。容器管理商品逻辑位置，Tween插值可视位置补偿，避免容器覆盖动画。画布变换的逆矩阵把商品坐标转换到检视层；Shader控制覆盖、同层不透明渐变和溶解。视觉完成回调不承担交易提交，防止关闭或中断造成重复奖励。

当前参数以代码为准，替代早期调试记录：暗单停留0.7秒、渐变0.35秒；桌布位置(224,40)、尺寸(832,306)；商品补位0.24秒，包装放大0.25秒、停留0.12秒，包装／卡牌检视4倍。详见 [商店动画说明](SHOP_ANIMATION_20261003.md)。
