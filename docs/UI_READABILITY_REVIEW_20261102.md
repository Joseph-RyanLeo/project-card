4. **日志保持前景。** 战斗日志使用绝对3900层与不透明底板，盖住战后统计、装备指示物及其悬停预览；公式提示为3950层，检视为4000层。鼠标移到日志覆盖的装备位置，也由日志接收输入，不弹背后卡牌。原日志滚动、公式链接和悬停2倍放大继续保留。
5. **积分明细使用图片。** “查看得分详情”展开两列可滚动图片条目：每张卡显示实际实例卡面与六项积分组成，工具箱逐枚显示真实纹章、元素贴纸或伤势图片，金币使用金币图案。滚轮连续浏览，图片只读，不再入账。新总结冻结卡牌完整快照和贴纸状态；恢复时核对快照身份。旧总结没有这些可选字段仍可读取，优先使用已有候选快照，否则显示定义图，不补造外观或符文。
6. **比较界面随画布缩放。** 用已有CardInspectionOverlay构成1200×672的比较区，替代独立原生子窗口，使720p／2K都按相同逻辑画布缩放。四张卡固定逻辑2倍，即720p宽198像素、2K宽396像素；原子窗口在2K下没有同步放大，是旧截图看起来小的原因。移除“卡面／效果”翻面按钮，卡下直接列出效果、实例、来源和战绩，各列独立滚动；保留替换二次确认与最终统一入藏。
7. **采用精细加粗文字。** 旧寒蝉7px点阵字模即使增大字号，仍保留低分辨率轮廓。一般界面和按钮改用项目已带的Noto Sans SC可变黑体、650字重；日志正文14号，菜单和标题按原布局使用较大字号。按钮上下内距相应收紧，避免较高黑体行盒撑出720p菜单。卡面点阵字及图标数字素材继续各自使用原方案。

## 脚本与数据职责

- `tests/d2_7_ordinary_shop_test.gd`：完整旧商店回归。使用当前UI控件信号及真实服务／保存；取消使用带通知的`return_card()`，等待延迟刷新后再进行下一次输入。清理完成后才释放Main，避免尚在归位的协程被中断。
- `scripts/main.gd`：战斗收板按钮的禁用条件、日志／公式层级、一般界面主题和14号日志正文。原交易规则与计分公式没有改变。
- `scripts/ui/card_effect_popup.gd`：共享窗口通过`can_show_effect_popup()`、`prefers_effect_popup()`、`get_effect_popup_title()`与`get_effect_popup_text()`读取来源，不再假设所有来源都是CardView。
- `scripts/ui/card_view.gd`与`celestial_indicator_view.gd`：分别提供卡牌和指示物的同一套显示接口，真实状态仍保存在各自的OwnedCard／CelestialIndicator中。
- `scripts/data/run_score_service.gd`：在既有得分条目增加可选`cards[].snapshot`与`toolbox[].sticker`，用于结算时图像，不重新计算或发放积分。
- `scripts/data/profile_progress.gd`：新增图片快照身份检查，同时接受没有这些字段的旧总结；同档原JSON与凭证事务保持原结构。
- `scripts/ui/slot_hub.gd`：GridContainer＋ScrollContainer组织图片明细；只读CardView和现有贴纸素材提供图片。比较界面与大卡检视复用已有覆盖层；比较卡不再进入独立Window，因此不会遗漏显示壳的2K倍率。
- `scripts/ui/ui_typography.gd`：缓存一份650字重FontVariation；菜单主题、Main、棋盘按钮与事件文字共用。正文和标题的具体字号仍由各控件声明。

## 初学者需要理解的写法

`return_card(false)`用于交易内部归还，刻意不通知服务状态变化；模拟用户取消则应调用`return_card()`，由信号清空当前选择并延迟刷新。等待刷新后再发下一次输入，才等价于用户连续操作，不能在同一帧反复操作旧按钮状态。

FontVariation是在同一个可变字体上指定字重，不是描边伪造粗体。OpenType轴标签由TextServer在运行时提供，所以用`static var`缓存字体对象；所有控件共用一份资源，不逐个加载字体文件。

`z_as_relative = false`让日志层级不受战场祖先节点影响。3900／3950／4000依次区分日志、公式说明和检视。底板不透明则避免背后的统计图案透入正文。

`duplicate(true)`复制嵌套数据，保证贴纸和卡面在结束时冻结。图像页面读取被冻结的字典，展示与积分计算分工明确；看图、滚动、比较都不会改积分或提前替换旧收藏。

## 后续调整：替换对比卡的悬停检视

替换界面的本局候选与三个已有收藏位均接入同一份悬停检视画布。鼠标在卡内移动时产生与检视相同的透视高低差，移开后平滑回正；原卡位和2倍显示尺寸保持不动。关闭、隐藏或释放对比卡时归还显示层，避免留下浮动卡面。

`collection_card_hover.gd`的`bind_read_only()`负责只读卡的鼠标命中和生命周期，`collection_candidate_card.gd`与`slot_hub.gd`共同调用；实际倾斜继续由已有`InspectionCardSurface`驱动，不为四张卡各建一份持续渲染画布。卡牌快照和收藏选择数据不变。

`gui_input`传入的是命中控件的本地坐标，除以原卡尺寸后统一映射到-1～1，因此1倍候选、2倍比较卡以及2K窗口都使用相同的倾斜幅度。`MOUSE_FILTER_PASS`允许点击和滚轮继续交给父级，而可见的检视画布保持`MOUSE_FILTER_IGNORE`，避免倾斜图像遮住原卡输入。信号回调只在进入、移动、离开或释放时更新共享画布。
