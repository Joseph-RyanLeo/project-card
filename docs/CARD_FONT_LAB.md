# 卡名字体调试器（2026-10-30）

进入游戏后按Esc，选择“卡名字体调试”。调试器沿用1280×720逻辑画布，右上保留窗口尺寸菜单，可直接比较720p、1080p与2K。名字的可用区域始终为61×9px。

## 使用方法

右侧同时展示四行字体和三列抗锯齿设置：

- Noto Sans SC：当前使用的矢量黑体，名义字号9。
- 缝合像素8px：小尺寸黑体风格点阵字，名义字号8。
- 缝合像素10px：较多笔画的黑体风格点阵字，名义字号10，仍放入9px高的可用区域，实际裁切由图像判断。
- 寒蝉点阵：原字体对照，名义字号8。

列分别是关闭抗锯齿、灰度抗锯齿与LCD子像素。LCD可能出现彩色边缘；后续合成与窗口缩放也会影响观察，按实图判断。每格上方是1倍原图，下方是同一原图的4倍最近邻放大。点击任意一格，左侧选中该字体、抗锯齿与原生字号。

左侧可以直接输入卡名，或者从样本下拉框选择。可调参数包括名义字号、矢量字重、Hinting、子像素定位、字体采样倍数、上下偏移、放大倍数及长名字是否按61px宽度缩字。字重只对可变矢量黑体启用。上下偏移以原生像素计，范围−4至4，区域高度始终保持9px。

下方左侧放大镜将同一张61×9纹理放大2～10倍，可打开像素网格；右侧展示完整19px高行盒，红线之间是实际9px区域。对比红线外的笔画，可以判断当前上下位置是否裁掉字形。

“应用到卡牌”会保存当前调试参数，并将字体、抗锯齿、采样、名义字号、上下偏移和长名缩字设置应用到实际卡名，然后自动返回游戏查看。卡名区域仍为61×9px；既有卡面与之后新建的卡面都使用已应用设置。此设置独立于卡牌／弹窗显示模式，切换模式不会丢失卡名选择，正文和弹窗字体不受影响。

已应用卡名参数保存在本机 `user://card_text_display.cfg`，重新运行也会恢复；调试样本文字、放大倍数和像素网格只用于预览，不会写成真实卡名。“保存参数”仅保存 `user://card_font_lab.cfg` 供下次继续调试；“恢复初始”只重置本次控件，需再次点击应用才改变实际卡名。按Esc或“返回”可直接退出而不应用新调整。

## 功能如何组织

输入卡名或调整控件后，`card_font_lab.gd`将参数组合成一份配置，为各候选创建独立字体资源；文字只在61×9的SubViewport里以原生字号绘制。1倍图、4倍图和放大镜共用同一ViewportTexture。窗口分辨率切换继续由GameDisplay处理，没有更改正式卡牌渲染路径。

主要文件与数据：

- `scenes/tools/CardFontLab.tscn`：独立工具场景，可以从Esc菜单进入。
- `scripts/tools/card_font_lab.gd`：构建界面，`FONTS`引用共用字体清单；`DEFAULTS`保存调试初始值；`controls`关联各控件；`comparisons`保存12组原生采样；`selected`与`full_sample`保存当前裁切和完整行盒。
- `_make_font()`：缓存调试字体，复用共用的字体创建函数，保证预览与实际卡名的参数相同。
- `scripts/ui/card_text_display_settings.gd`：`NAME_FONTS`保存共用候选清单，`make_name_font()`复制并配置字体资源；`apply_name_profile()`记录应用参数、保存本机偏好并通知现有卡面更新。
- `scripts/ui/card_view.gd`：`apply_card_name_typography()`只刷新卡名，`_set_card_name()`处理字号和长名宽度，`_layout_name_label()`处理行盒与上下偏移；不修改卡牌数据或效果显示。
- `_update_sample()`：按61px宽度拟合长卡名，计算行盒居中位置与上下偏移，标记采样画布重新绘制。
- `_queue_refresh()`／`_refresh_previews()`：合并一帧内的多次参数变化，更新实际图像与行高／缺字提示。
- `get_profile()`／`save_profile()`／`load_profile()`：读取、保存和恢复独立调试参数。
- `game_display.gd`：`open_card_font_lab()`／`close_card_font_lab()`管理工具；与原卡包工具复用来源暂停和恢复函数。

## Godot写法说明

`FontFile.duplicate()`为实验建立独立资源；直接修改通过 `load()` 取得的共享字体，会影响仍在使用它的卡牌，因此不能直接改原资源。应用后由设置脚本缓存一份共用卡名字体，所有实际卡牌引用它；继续调整调试器使用另一份实验资源，直到再次应用才影响卡名。

`SubViewport`是独立的小画布，这里固定为61×9，并且保持单位画布变换。`ViewportTexture`是该画布的输出图像；放大TextureRect只放大已有像素，避免用大字号重新绘制后产生误导性的清晰效果。

`UPDATE_ONCE`表示参数改变后只绘制一次；用户没有继续调整时，样本不用逐帧重新渲染。`call_deferred()`把同一帧内的控件变化合并到稍后统一刷新。

`process_mode = ALWAYS`让调试器在游戏暂停时仍能操作；来源游戏临时隐藏并关闭输入，退出后恢复原状态。字体实验不推进卡牌数据或玩法随机数。

## 字体来源

缝合像素来自作者官方项目 [TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font)，使用2026.10.25发行版的简体中文等宽TTF，未修改字体文件。字体及原始OFL与上游字源许可证保存在 `assets/fonts/font_lab/fusion8/` 和 `fusion10/`。只导入已生成字库，不引入其构建工具或运行依赖。
