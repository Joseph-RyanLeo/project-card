# 阶段 6.5：敌人位置与收藏系统

阶段 6.5 把主界面改造成“敌方战场 → 我方战场 → 收藏册”的纵向世界，并以收藏正式取代原手牌概念。准备阶段默认查看我方战场与收藏，战斗/结算默认查看敌我战场；人物按钮可在两种视角间平滑切换。

## 主要更新

- 敌方后排、敌方前排、我方前排、我方后排按玩家视角自上而下排列；四排都复用 `BattlefieldRow`、21 单元容量、`SquadData`、牌型标签和符文流光。
- 敌方使用固定测试小队，始终关闭拖拽、换序与堆叠入口；本阶段不实现敌方 AI 或战斗。
- `WorldContent` 保存三段世界坐标，视角切换只平滑改变它的 Y 位置；人物按钮属于我方战场，所以会自然落在准备视图右上区域和战斗视图右下区域。
- 项目虚拟画布继续固定为 `1280×720`。纵向世界是 `1280×1080`：上视图显示世界 `Y=0～720`，下视图显示 `Y=360～1080`，两者重叠的 `360px` 正是始终可见的我方战场。
- 正式高清素材已按桌面木纹 → 战场背景板 → 装饰桌布 → 木板垫 → 战场锦缎 → 实时卡牌的顺序分层；每层都是独立 `TextureRect`，后续可单独换图。
- 敌方人物与我方人物同时存在。敌方人物固定正面且不可点击；我方人物在上视图显示背面、下视图显示正面，点击它时人物朝向和纵向视角一起切换。
- 四排卡牌顶边经过人工校准后固定在纵向世界 `Y=48、202、382、536`，不再由锦缎边界和临时内缩量组合推导。
- `collection_cards` 保存玩家拥有的全部卡牌，不因部署到我方战场而删除；我方战场只保存同一 `CardData` 的部署引用。显示顺序由 `get_filtered_collection_cards()` 固定按稀有度 `V→I` 派生，同稀有度保持进入收藏时的先后顺序。收藏上限改为 100 个物理单页，每页 6 张，即 50 组展开页、最多 600 张。
- 当前 Demo 直接加载 24 张卡名和卡面均不重复的 `CardData` 资源：保留原有 3 张卡面，并加入“灰烬征册”的 21 张卡面，正好铺满 4 个物理页。页数按当前筛选结果动态计算，不再创建结果范围之外的整张空白页；左右下角分别显示物理页码。
- 收藏卡保持 `99×136px` 并可放入战场，但玩家不能调整收藏内的位置。卡牌部署后，原排序槽持续显示不可交互的半透明卡面虚影，其他卡不再缩进；场上卡或小队放回后，同一槽位恢复为实体。拖拽期间书边和滚轮都拒绝翻页。
- 左右书边、滚轮和测试入口共用 `turn_collection_page()`。每次动画先建立旧固定页、目标固定页和唯一活动页三个独立快照：例如 `1、2 → 3、4` 时固定第 1、4 页，活动页由第 2 页切为第 3 页。活动页先以书脊侧为转轴压到零宽，中点切换物理页、页面侧别与转轴，再向另一侧展开；第 4 页随第 2 页收起逐渐露出，第 1 页则被展开的第 3 页逐渐覆盖。三个快照就绪后才隐藏实时收藏卡层，动画完成后恢复目标展开页，因此不会缺少固定目标页或重复绘制目标卡。卡牌、文字、物理页码、纸张和 4px 动态页边始终使用同一个变换根节点；页码复用卡牌基础数值的数字字体，并随固定页或活动页一起遮挡、收缩、换面和展开。
- 原五个顶部标签正式改为近战、远程、法术、治疗、防御筛选；新增随从、法术、装备、资源四个卡牌种类书签。行动方式与卡牌种类都采用组内互斥单选，并与其他筛选使用 AND。被选中的书签会先越过目标位置，再回弹到抽出状态；取消时也会越过缩回位置后回弹。
- I～V 稀有度按钮采用互斥单选；元素按钮支持多选并要求卡牌同时包含全部所选符文。稀有度与元素的每个圆形图标现在都是独立 `TextureButton`：按钮自身显示对应图集裁片并负责点击，不再叠加一张完整图集造成重复圆点。选中时显示勾标记。
- 普通收藏页直接使用独立的 `collection_left_page_front.png` 与 `collection_right_page_front.png`，不再显示错误的合并底板。翻页快照也读取同一对正面素材，静态页与动画页保持一致。
- `recently_returned_cards` 保存最近从战场成功放回收藏的 12 张卡：最新优先、同卡去重并移到最前。蓝色书签切换一组独立的最近使用左右页；普通状态层级为书皮 → 书签 → 普通页，最近使用状态为书皮 → 书签页 → 最上层书签，再次点击返回此前普通页。进入最近页时书签向左抽出并回弹，每次有卡从战场回收时书签会小幅摆动。
- 搜索与筛选交互层使用高 `z_index` 且固定为收藏区域的最后一个子节点；搜索图片从原图集单独裁出，放大镜、输入框与 X 的命中范围都使用相对该图片的同一组坐标。输入框的 `text_changed` 会即时更新名称、种族和效果文字筛选，回车与放大镜仅重复执行同一条搜索路径。
- 旧横向收藏区、大卡预览、旧标题和可见阶段按钮已经删除；卡面调整器入口与 `BadgePanel` 强化徽章预留节点保留。

## 主要代码职责

- `scenes/Main.tscn`：只保存主场景根节点与初始收藏资源；运行时固定卡位和世界结构由 `Main` 一次性建立。
- `scripts/main.gd`：建立三段世界、控制视角与阶段、保存真实收藏、执行筛选分页，并提交收藏和我方战场之间的数据事务。
- `assets/stage_6_5/`：保存裁成项目宽度的桌面、收藏册底座与四张书页纹理，以及战场四层和人物正反面精灵图。
- `scripts/ui/collection_drop_zone.gd`：只接收我方战场卡牌/小队放回收藏，拒绝收藏来源卡以阻止收藏内换序；它只转发数据，不直接改真实收藏。
- `scripts/ui/battlefield_row.gd`：继续负责敌我战场行容量、布局、预览和放置意图；敌方通过关闭拖拽复用同一显示能力。
- `tests/stage_6_5_enemy_collection_test.gd`：验证四排、双视角、阶段锁、100物理页/600张边界、书脊转轴翻页、最近使用书签、即时筛选搜索和收藏事务。

## 收藏 UI 调整入口

以下常量都集中在 `scripts/main.gd` 顶部，修改后重新运行主场景即可观察结果：

- `LEFT_PAGE_NUMBER_POSITION`、`RIGHT_PAGE_NUMBER_POSITION`：左右物理页码位置；`PAGE_NUMBER_SIZE`、`PAGE_NUMBER_FONT_SIZE`：页码区域与基础数值字体字号。
- `RARITY_FILTER_POSITION`、`ELEMENT_FILTER_POSITION`、`SEARCH_FILTER_POSITION`：稀有度、元素与搜索组。
- `ACTION_TABS_POSITION`：整组行动方式书签；`ACTION_TAB_ICON_POSITION`：行动图标相对单个书签。
- `CARD_TYPE_TABS_POSITION`：整组卡牌种类书签；`CARD_TYPE_TAB_REST_Y`、`CARD_TYPE_TAB_SELECTED_Y`：缩回与抽出高度。
- `RECENT_BOOKMARK_POSITION`、`RECENT_BOOKMARK_SELECTED_OFFSET`：最近使用书签的基础位置与选中抽出量。
- `TAB_OVERSHOOT_PIXELS`、`TAB_OVERSHOOT_DURATION`、`TAB_SETTLE_DURATION`：所有书签越位与回弹的距离、前段时长、回弹时长。
