## 通用规则

| 编号 | 已确认 |
|---|---|
| G1 | 通用事件替换旧测试事件。优先抽取玩家本局尚未翻开且未通过预见看到内容的事件。只看到牌背的事件仍可出现，同一牌背可以指向不同事件。先抽不同的未见事件，再回用不同的已见事件。若合格事件总共仍不足三种，允许同轮重复补满。 |
| G2 | 普通随机和点名奖励默认遵守本局解锁与启用限制，只有明确指定的事件例外。以解锁卡包为入池条件的事件默认按本局启用判断。雾中人有明确例外，见 E05。 |
| G3 | 付费选项的任一结果无法兑现时，整项不可执行，直到有专门的替代规则。指定卡奖励遇持有唯一限制时，走专门替代分支或置灰。保留原概率。赌坊有更具体的显示规则，见 E02。 |
| G4 | 补一个直接离开的选项，供选卡、奖励等条件导致无可执行选项时使用。具体效果无目标或槽满时按该事件条目执行。 |
| G5 | 「下回合」指下一场战斗，事件插入的额外战斗计入。全队效果在对应战斗正式结算后消耗。绑定单卡的三场加成在该卡实际参战且战斗正式结算后扣一次，战中退出并恢复战前时保留。 |
| G6 | 未标权重的具名清单等概率。普通随机大／小包每包在本局启用的普通主题中独立抽主题。天选之子、厄运缠身均不影响事件骰，事件骰也不计入厄运的骰点统计。 |
| G7 | 奴隶贩子的三个牌背为恶魔正位、恶魔逆位、力量正位。其他事件使用源表牌背组合。逆位将同一插图旋转 180°，缺正面图时使用通用图。现有事件 ID 供兼容旧档，新增事件分配固定 ID。 |

## 事件专属药剂

事件的小型禁药直接生效，中型与大型先作为物品领取。普通药剂的单项、合剂和完美合剂共用四种基础效果。卡面按净增减显示数值、生命、护甲和热诚，热诚保留原装备卡位置。效果写作「突击：消耗并使装备者获得属性」。

| 档位 | 品级 | 候选与效果 |
|---|---|---|
| 小型禁药 | I | 力量永久 +1/+2。热血永久热诚 +5。刚毛永久保护 +1。三者都额外附加一个随机不可清除伤势。 |
| 中型禁药 | III | 蛮力永久 +3/+5。沸血永久热诚 +10。硬皮永久保护 +4。三者都新增一个随机不可清除伤势，并随机升级一处伤势使其不可清除。升级可选中本次新增的伤势。 |
| 大型禁药 | V | 神力永久 +2/+2，然后将基础数值、生命和护甲翻倍。燃血永久热诚 +30。石肤永久获得每场战斗开场的 10 秒免伤。三者都将全部纹章与伤势栏位转为不可清除的 I 级伤势。 |
| 基础药剂 | I | 骨刺永久基础数值 +1、基础生命 −1。强心永久基础生命 +2。迅捷永久热诚 +1。厚壳永久基础护甲 +2。免费试用对选中的随从立即生效，结果页展示抽中的药剂卡。 |
| 组合／完美合剂 | II／III | 中型从四种基础药剂抽两个不同效果。完美合剂的净增量为基础数值 +1、基础生命 +1、基础护甲 +2、热诚 +1。领取装备卡，突击消耗。 |

小型与中型禁药从 I 级伤势抽取。新增伤势时槽满则改为升级一处可升级伤势，无候选时跳过。中型交换消耗 I–III 各一张随从，大型另消耗一张 IV 级随从，均从该档三种装备等概率抽取一瓶。药剂装备在突击时消耗，永久效果随正式战斗结算写回。
