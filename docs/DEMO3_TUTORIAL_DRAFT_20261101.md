# 四天新手教程流程与敌人初版（2026-11-01）

本稿整理用户已确认的教程节点，并落实用户授权的“敌人先配置、不要太难”。仍处于D3设计阶段，未修改现有Demo2遭遇、赠包或路线代码。

## 已确认的教程流程

- **1-0开局准备**：获得灰烬证册开局包，将伊奥恩原有5张初始卡以卡包形式发放：粗麻绷带、火枪手、城镇牧师、盾墙列兵、悲歌诗人。内容固定，不使用普通包随机抽卡，也不在包外再发一套5张；不将该开局准备节点算作多完成一天。
- **1-2铁匠引导**：找到铁匠，获得铁砧-玛格丽特及无限刮刀。无限刮刀从此节点取得后持续到本局结束，沿用不占装备位的常驻任务效果；不再从1-0起自动开放。
- **1-4教程终点**：完成四天短路线，按既有规则计通关、剩余保护倍率、收藏，并额外赠同档一次1,000积分，引导继续纹章包试炼。
- 提示允许跳过；已阅提示从Esc“教学帮助”重看，失败重试不自动重复弹出。完整事件和人物文案由用户随任务树后补；未据此增加强制练习或恢复开发者学习验收。

开局卡与赠卡复用已有资源定义：[粗麻绷带](../resources/cards/coarse_bandage.tres)、[火枪手](../resources/cards/musketeer.tres)、[城镇牧师](../resources/cards/town_priest.tres)、[盾墙列兵](../resources/cards/shieldwall_private.tres)、[悲歌诗人](../resources/cards/elegy_poet.tres)、[铁砧-玛格丽特](../resources/cards/anvil_margaret.tres)。未改这些卡的属性或特效。

## 敌人配置初版

定位为低压力教学，先让玩家体验摆放、战斗、卡包和刮符文。敌人只用现有正式卡，不增加专属Boss卡或复杂机制。

| 日期 | 前排独立小队 | 后排独立小队 |
| --- | --- | --- |
| 1-1 | 民兵×1 | 无 |
| 1-2 | 民兵×1、胆怯的步兵×1 | 无 |
| 1-3 | 民兵×2 | 火枪手×1 |
| 1-4终点战 | 盾墙列兵×1、民兵×1 | 火枪手×1 |

- 每张敌卡独立成队，不堆叠、不额外装备、不准备法术、不附加英雄被动。
- 敌方不揭晓符文、不追加纹章；四天教程使用这份独立配置，不套用普通短路线的两天一档额外纹章成长。
- 不额外指定手动部署资源；本次难度验证不放资源，不能据此宣称已经验证所有自动资源奖励组合，或把普通资源系统永久关闭。
- 1-4只作为四天教程终点，通关结算沿用已确认规则，不将它当成各层第8天Boss额外加0.5倍率。

## 难度验证与范围

使用当前Godot项目中的真实OwnedCard、SquadData及BattleController进行临时验证，未使用替代战斗计算。4关各20个种子，共80场；日志显式写入`/private/tmp/project-card-tutorial-balance-20261101.log`，进程退出码0。
