# 卡牌与事件板七项反馈修正

2026-11-02，依据用户四张截图与3.77秒录像，在主目录 main 顺序实现。保留既有未提交工作，不新建分支／工作区，不升级引擎或添加依赖，未提交或推送Git。

## 输入到结果

1. 收藏右侧名称、副标题以及“卡牌详情 / 积分构成”页签改为项目已有中文黑体，与两页正文统一；左侧像素卡面沿用原设置。
2. 将效果仍写着“占位”的29张演示卡在独立CardData资源中设为`is_available = false`，退出普通商店、卡包、随机奖励与获得时赠卡候选。旧商店存档中的停用单卡不再陈列，未开的整包会按当前可获得池核对。资源及已经拥有的实例保留，卡面调整器仍能扫描；未把正式卡暂缺卡图的情况当成停用依据。
3. 装备热诚为0时，数值在原位置上向右移3个逻辑像素，靠近火焰中心；有正负号的装备和随从冷却不改位置。
4. 指向已装备的装备指示物时，完整装备预览旁使用共享效果框，按预览卡定位在上方或下方，边缘自动避让；移开或开始携带时收起。卡牌文字模式下也保留此装备说明，移除原生“拖回收藏可卸下”长提示，避免叠在卡面上。
5. 卡包虚影由“当前预抽内容能否获取”决定，并非仅看金币。已复现：未购买包的预抽结果含唯一装备，玩家随后从别处获得同名装备，旧实现就禁用整包。现在合法预抽内容继续沿用；若其中卡牌因为当前持有或停用而失效，则在原主题／行动候选内重新去重，仍满足原张数、大包II级保底与唯一持有规则。预览只使用随机源副本，不改商品、不消耗实际随机流；购买时提交重核结果，保存失败回滚余额、实例、原包内容及随机状态。错误主题、未知卡、张数错误或同包重复唯一卡仍拒绝；真正缺少合法候选时不扣款。
6. 同一天的四个轮次按“旧图向上滚出、新图从下方滚入”的轮盘方式切换，沿用已有0.24秒动画。新棋盘顶栏以前直接替换贴图，现在读取世界顶栏同一份滚动进度并裁剪显示，不复制天数或轮次状态。
7. 下半场选择战斗牌后，事件提示板保持覆盖在当前屏幕上方，不自动移出画面。只有点击收起按钮后，才以原0.30秒动画返回世界顶部902×351区域（世界最上约1/3）；之后切换上下视角和刷新都保持在那里。视频中的突变来自战斗准备状态自动换父节点，现已移除该自动锚定。开战仍按原流程收起事件板、显示敌方阵容。

## 关键脚本与数据

- `scripts/ui/slot_hub.gd`：仅右侧名称、副标题和TabBar增加字体覆盖，复用`CardTextDisplaySettings.readable_font()`。
- `resources/cards/`下29个占位定义：停用开关位于`script`绑定之后，供Godot按CardData导出属性读取。普通获取沿用现有`OrdinaryShopService._eligible_cards()`、英雄法术候选及获得时赠卡的可用性检查，没有另建白名单。
- `scripts/ui/card_view.gd`：`ZEAL_ZERO_VALUE_OFFSET`集中声明零热诚偏移，刷新数值时应用。
- `scripts/ui/equipment_indicator.gd`、`card_effect_popup.gd`：预览仍引用同一个OwnedCard；共享效果框以真实预览卡为锚点。沿用`inspection_hover_owner`识别指示物预览，允许其在两种文字模式下显示说明，仍受携带／暂停／来源隐藏检查控制。
- `scripts/main.gd`：`_resolve_shop_card_pack()`负责当前包内容重核，`_can_buy_shop_card_pack()`复用其结果；购买仍通过原保存事务。`_sync_tabletop_panel_anchors()`不再把新选战斗板自动挂回世界，`_resume_tabletop_follow()`保留手动收起后的战斗板位置。
- `scripts/ui/tabletop_header.gd`与`maze_run_hud.gd`：世界顶栏维护原来的两组标记和Tween，棋盘顶栏读取其贴图与位移，在13×13窗口内绘制可见部分；结束后恢复单个静止图标。

## 初学者需要理解的写法

主题覆盖只作用于指定Control。因此正文、名称和TabBar分别指定同一黑体资源，避免只改父容器却没有真正改变字形。

`RandomNumberGenerator`的`seed`和`state`可以复制到新对象。商品可购检查在副本上抽取，得到一份“候选卡＋后续随机状态”；实际交易才提交该状态。这样反复悬停、刷新显示不会重抽玩法随机数，保存失败也能完整恢复。

`reparent()`改变节点的坐标归属。屏幕层里的事件板不受世界相机滚动影响；世界层里的板会随世界移动。手动收起时先保留屏幕位置再Tween到世界顶部，避免换父节点瞬间跳位。是否已手动收起继续使用现有`_tabletop_panels_parked`，不另存一份战斗板状态。

轮盘用旧图和新图两层纵向移动，通过可见矩形与13×13槽位求交来裁剪。棋盘顶栏只读取同一个动画进度，不修改`run.day`或`round_index`。
