## 已接通的浏览方式

- 卡包分类：只列本档已开放、且有正式可入藏定义的卡包，顺序沿用`CardPackRegistry.PACKS`。每个分类独立分页，不把不同卡包混排。没有开放分类时给出空目录，不自动补解锁。
- 种族筛选：十种种族身份，只筛适用的随从；非随从不会因为共享字段的默认“人类”被筛入。无种族随从可用“无种族”条件查找，不给未知卡补造种族暗示。
- 类型筛选：随从、物品、法术，可以与种族同时使用。资源留待独立图鉴区。
- 搜索：支持已发现基础定义的卡名、前排／后排效果，自动忽略首尾空格并进行大小写归一。未知卡在比较名称／效果前就被排除，输入其精确卡名也不会找到占位。
- 翻页：上一页／下一页按钮，也支持PageUp／PageDown；每张双页最多六种。首尾禁用对应按钮，不循环到另一端；没有结果显示`第0/0页`和清除筛选提示。
- 分类或条件改变时回第一页；切换分类保留当前筛选与搜索，清除筛选只清条件，不切分类。返回大厅后再次进入从默认分类／第一页开始，浏览状态不写入玩家档案。
- 顶部同时显示本包和全册发现进度。筛选和翻页不改变分母，全册包含尚未开放的正式内容。这里的“全册”指当前可入藏卡牌目录，不冒充资源／贴纸／衍生图鉴总数。

## 一、输入到结果的流程

进入展览馆时，`GalleryBook`从当前`ProfileProgress`读取开放卡包，构建分类菜单；从缓存的正式定义中查询所选卡包，再按种族、类型和已发现文字搜索生成`filtered_cards`。列表保持原来的品级降序和同品级ID稳定顺序，不重新排列三个实际收藏位。

`page_index`决定从筛选结果中切出哪六种放入`shown_cards`。双页面板和表头始终复用，切页时只释放当前卡位节点、重建新六种的基础卡／暗示和三个收藏位。不会为整册130种、最多520个卡位同时创建CardView或高分辨率画布；悬停仍复用原有唯一显示层。

绘制前先关闭不再适用的检视并释放悬停，再清理旧节点。正常检视中的PageUp／PageDown不翻动后方收藏册；菜单打开时Esc先收起菜单，检视打开时Esc先缩回卡牌，收藏册中Esc才返回大厅。筛选后打开的实例仍从本档完整快照读取外观、成长、来源与战绩。

所有查询只读取永久发现、解锁和收藏。页面没有发现提交、存档写入、扣分、发分、替换、删除或调位操作。

## 二、数据与函数职责

本轮直接扩展已有两个脚本，没有再叠一套目录或页面：

- `scripts/data/gallery_catalog.gd`：原有正式定义缓存、身份去重和显示资格保持；新增`unlocked_packs()`提供分类，`filtered_cards()`负责组合筛选和保密搜索。`count_total()`／`count_discovered()`可按一个卡包或整个卡册统计，统计不依赖当前筛选结果。
- `scripts/ui/gallery_book.gd`：原有双页尺寸、行高和四列位置保持。`_build_filters()`创建原生OptionButton／LineEdit；`_filter_changed()`重算结果并归第一页；`page_count()`算总页数；`change_page()`检查边界；`_draw_page()`只绘制当前六种并刷新页码、按钮、进度和空结果提示。
- `_pack_ids`／`_pack`：本档可展示的分类及当前分类；不是第二份解锁数据。
- `filtered_cards`／`shown_cards`：当前分类和筛选下的完整结果／当前双页切片。
- `page_index`：从0开始的当前双页编号，只存在页面内存中。
- `_pages`／`_row_nodes`／`views`：复用的双页面板、当前卡位节点和当前已发现／实际收藏卡面的查找表。翻页先释放共享悬停，再清掉旧卡引用。
- `ProfileProgress`、`OwnedCard`和`read_only_card_inspector.gd`继续承担原有数据与只读检视职责，本轮没有改写它们。

目前正式可入藏定义共130种：灰烬证册30种／5张双页、铁壁铭刻34种／6张、银月之章34种／6张、扭曲矿脉31种／6张、迷宫1种／1张（矿镐沿用主要归属）。尚未开放分类隐藏，但这些定义仍计分母；开发演示、资源和衍生不混进这份可入藏目录。正式停用的发现／收藏显示规则沿用首版，没有修改资源身份。

## 三、需要单独理解的GDScript写法

- `slice(first, first + 6)`：从完整筛选结果中取当前双页的一段，结束位置不包含在内；最后不足六种就只显示剩余种类。`first = page_index * 6`，显示页码再加1。
- `ceili(...)`：向上取整，34种除以每张六种得到六张；0种得到0张。`clampi(...)`限制页码范围，避免末页之后出现额外空页。
- OptionButton的第0项是“全部”，所以用`selected - 1`传递筛选值；结果`-1`表示不限，不是新增一种种族或类型。
- `item_selected`／`text_changed`是原生控件信号，统一交给`_filter_changed()`，减少每个控件各写一套更新逻辑。清除多个条件后也走同一条路径。
- 翻页前直接`free()`当前卡位，再清空`views`：立即去掉旧卡的输入与显示，避免本帧重建时旧卡仍可被命中。延迟右键回调先用`is_instance_valid()`检查源卡，防止切页后引用已经释放的节点。
