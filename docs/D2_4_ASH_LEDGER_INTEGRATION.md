# D2-4 灰烬证册接入计划

D2-4 接入灰烬证册全部 21 张随从资源。20 张启用随从的 26 条活动效果进入正式战斗与战斗实验室；城镇牧师保留卡牌资源和收藏站位，但保持 `disabled`、不绑定活动效果。

灰烬证册之外继续保留三张开发站位卡：余烬侍从、潮汐射手、星火法师。余烬侍从与星火法师的特效栏为空。潮汐射手显示“开采：+1强化”，但只记录 `mining_succeeded → add_reinforcement(1)` 的延后钩子；D2-4 不实现开采目标与结算，也不允许其他触发代替。

## 小步顺序

1. **资源与绑定基线**：把 21 张随从的确认数值、可用状态、槽位、关键词和效果 ID 写入真实 `CardData`；正式战斗按卡牌 ID 自动登记效果；实验室可选择 20 张真实效果卡。自动测试锁定 21 / 20 / 26 数量与潮汐射手边界。
2. **已具备运行时能力的效果**：先完成强化、热诚、护甲、基础属性、行动倍率、受击优先级和邻接目标，使对应卡牌可以形成完整战斗断言。
3. **战斗事件接线**：接入回响、治疗后、受击后、累计失去生命、相邻/其他友军死亡和分组步骤，补齐稳定顺序与每场次数测试。
4. **战中专用行为**：实现禁止堆叠、遮蔽符文、即时行动、行动方式切换，以及 D2-4 范围内可以独立完成的临时状态。
5. **依赖系统边界**：复活、随机加卡、金币、伤势遮蔽和永久成长只实现战斗侧最小接口与可观察失败，不做跨战斗写回；分别留给 D2-5 或对应后续系统完成。每项接口须有明确轨迹，不能静默执行错误默认值。
6. **整包回归**：20 张启用随从逐张进入实验室预设和无窗口测试，确认 26 条效果均有成功路径或明确的阶段依赖；城镇牧师保持 0 效果。

## 当前第一步边界

- 已允许真实卡牌资源绑定到 D2-3 效果目录。
- 已允许正式 `BattleController` 与战斗实验室登记真实随从效果。
- 运行时尚未支持的 operation 继续输出 `unsupported_operation`，不伪造结果。
- 城镇牧师虽保留在收藏用于站位/卡面测试，但不会登记效果。
- 潮汐射手的延后钩子不被 `BattleController` 读取，因此突击、攻击、命中和普通行动都不能获得这 1 点强化。

## 第二步已接通的战中链路

- 行动倍率进入正式公式，符文刻匠的 `+0.1` 会作为独立乘法项显示和结算。
- 护甲变化后重新检查持续效果；护甲归零会撤销玛格丽特迟缓和符文刻匠倍率，重新获得护甲后恢复且不重复累加。
- 主弹道发射后产生来源限定的回响事件；战鼓乐师只响应自己的行动。
- 基础治疗完成后产生来源限定事件，为随军医者后续伤势目标系统保留真实入口。
- 正式获得护甲会产生来源限定事件；盾墙列兵的额外护甲带明确生成效果 ID，不会递归触发自身。
- 非衍生友军死亡与相邻友军死亡使用真实退场批次发出事件；悲歌诗人的两步奖励已能共享同一次死亡额度。
- 铸甲师的死亡入口已经存在；首次相邻友军阵亡时，会把永久护甲成长记入本场待结算账本，并立即增加本场基础/当前护甲。
- 民兵指挥官的相邻人类计数会在站位或存活状态变化后原地重算；光环增加时按定义同时补当前生命，光环减少或消失时只撤销生命上限、不扣当前生命；卡面允许显示暂时高于新上限的真实生命。
- 外交官、民兵与火枪手已接入持续属性和乡邻目标。乡邻要求效果持有者左右两侧都有同种族存活单位；民兵是目标规则特例，会影响自身及左右相邻的所有人类（包括单兵）；火枪手可按卡牌特例把受击优先级降到0。
- 所有实际扣除生命或护甲的伤害都在 `BattleSquadState.apply_damage_exact()` 统一累计战绩，因此普通行动、直接伤害和复活前承伤不会因调用入口不同而漏出结算卡面。
- 主战场计时器下方提供九位战斗种子器；准备阶段可编辑或随机生成，开战后锁定并在结算阶段继续显示，便于用阵容截图与种子复现随机目标和效果结果。
- 胆怯的步兵响应其他友军行动，独立累计至5层，并在自身实际行动后清空本效果贡献。
- 玛格丽特的护甲获得拦截器在正式护甲公式写入前同步读取；同名来源不叠加，固定执行“基础护甲×倍率，再加盾墙等追加值”。
- 老狼按存活来源为带“乡邻”标签的效果增加执行次数；多个老狼相加、不递归，并把同一来源的多次执行聚合为可撤销的单个运行实例。
- 标枪散兵的突击通过正式选目标、弹道、牌型、元素与行动后事件执行一次“基础数值+2”的远程行动；弹道发射后，本场行动方式覆盖为近战，战斗结束恢复且不写回卡牌资源。
- 泥腿三兄弟的“无法堆叠”作为不可被沉默移除的固有编队规则，由 `SquadData` 同时拦截来牌、目标小队、整队合并和伪造的多卡结果；拖放预览与最终提交共用同一判断。
- 泥腿三兄弟阵亡时会发出来源限定的遗愿事件，从当前仍生效的符文中随机遮蔽1枚；遮蔽只保存在 `BattleSquadState`，牌型、行动倍率、元素统计与卡面空槽立即读取同一结果，战斗结束后清除且不写回 `CardData`。
- 同一次遗愿随后尝试在原位置重新入场：恢复满生命和卡牌基础护甲，不重复突击，并保留当前冷却、强化与已遮蔽符文。两步共享每场2次额度；第三次阵亡不再触发。若原位置已有存活单位，则结束本次遗愿并保留明确失败轨迹。界面通过生命代次取消旧退场动画，旧动画结束后也不能误删已经复活的卡牌。

## 第五步已接通的永久成长边界

- `BattlePermanentGrowthLedger` 保存本场已经确认的永久成长记录，但不直接修改共享 `CardData`。记录会保留到战斗结果阶段，开始下一场或清空战斗时才重置，等待 D2-5 的收藏卡实例系统消费。
- 每条记录包含实际受益卡牌、归属种类、成长属性、数值、效果 ID、来源战斗实例和逻辑时间。小队由多张卡组成时，成长归给触发当时真正提供行动值或护甲的单卡，而不是默认归给效果来源卡。
- 狂战先锋累计的是本场生命损失；治疗不会倒扣。累计达到8点后，本场最多记录一次基础数值+1，并把修正立即用于本场后续行动。
- 铸甲师在每场首次相邻友方随从被消灭时记录基础护甲+1，同时增加本场当前护甲；重新入场或后续阵亡事件不会重置次数。
- 账本目前只完成“战斗侧确认与暂存”。跨战斗写回、收藏卡唯一身份、存档与读取仍属于 D2-5，不能用卡牌资源文件代替收藏实例。

## 第五步已接通的外部系统边界

- `BattleRunRewardLedger` 记录战斗中已经确认产生的本局奖励，但不直接修改真实金币或收藏，结算界面也只读取记录。正常战后由 D2-5 对每条记录消费一次；中途重试清空，因此既不会提前污染本局状态，也不会重复发放。
- 征召官记录1次“随机随从请求”，并完整保留通常可获得随从池、Ⅰ～Ⅳ级、排除衍生/地牢卡和持有唯一排除等参数。D2-4 不在缺少收藏与本局卡池时伪造随机结果。
- 辎重驮夫把基础1金币与乡邻额外2金币拆成两条待结算记录。只有乡邻部分带“乡邻”标签，因此老狼只额外执行这部分。
- `BattleSquadState` 提供最小伤势注入与遮蔽接口。D2-4 不自行生成伤势；后续伤势系统传入稳定伤势身份后，随军医者会从仍生效、未遮蔽的伤势中随机选1处遮蔽5秒。
- 每个伤势遮蔽保存自己的运行实例来源；到期或战斗结束只移除本来源。已经被遮蔽的伤势不再进入随军医者候选池，无合法目标时留下 `no_legal_target` 轨迹并跳过。

## 战斗实验室配置预览

- 每方由4个扩为6个可配置小队槽，位置编号也同步扩到0～5。
- 每个小队可独立选择九种正式种族；实验卡构造后把该值写入 `CardData.race_type`，供民兵指挥官、外交官等种族条件直接读取。
- 未按“开始”时，实验室会建立不会推进时间的配置预览，只登记并计算持续光环，不触发突击、金币、随机加卡或其他一次性效果。
- 每次启用、停用、换排、换位置、换种族或更换效果后都会从基础配置重建预览，因此光环不会累计旧值，战场卡面会直接显示重算后的生命、护甲与行动数值。

## 第六步整包回归

- 21 张灰烬证册随从资源全部可载入；其中20张启用随从共绑定26条活动效果，城镇牧师保持停用且0效果。
- 20 张启用随从均已拥有真实战斗成功路径或明确的外部系统待结算边界，并进入战斗实验室选择列表。
- 城镇牧师、潮汐射手、余烬侍从与星火法师继续保留为最初站位卡。前三张指定卡牌的特效栏保持为空；潮汐射手只显示暂不生效的“开采：+1强化”。
- 聚焦效果、严格运行时、卡牌资源、战斗实验室、基础自动战斗与元素分层回归均通过；D2-4 未直接写入收藏、金币或共享卡牌资源。
