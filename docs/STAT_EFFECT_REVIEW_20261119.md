# 生命、护甲、数值与冷却效果核对表

2026-11-19 完成原实现核对，2026-11-20 收录玩家确认并更新实施后的规则。优先确认表保留实施前的差异与问题供对照。战斗检视显示当前值，文中的「白字」指基础比较基准。未开放的占位卡和只读取属性计算伤害的效果未列入逐项审阅。

## 术语

| 通道 | 对当前值／上限的影响 | 基础白字 |
| --- | --- | --- |
| 当前生命值 | 治疗、受伤、恢复和复活写入当前生命，不直接改上限 | 不改 |
| 基础生命值 | 原生值、有效水／光符文、永久基础成长等；加基础生命通常也提高上限，本场是否补当前值另看来源 | 改 |
| 最大生命值（正向加值） | 加上限，同时增加当前值；不等同于治疗，不抹掉原有缺血差额 | 非基础来源不改 |
| 空白生命值 | 只加上限，不补当前值 | 不改 |
| 上限下降 | 正常只降上限，不倒扣当前生命，不算伤害 | 只有基础值下降才改 |
| 当前护甲／初始护甲修正 | 获得、消耗和摧毁护甲改当前值；普通装备、纹章也可修正开战时的初始护甲，但不一定计入白字 | 非基础来源不改 |
| 基础护甲 | 明确的基础护甲与永久基础成长计入；永久增加时通常也加当前护甲 | 改 |
| 基础数值／普通数值修正 | 基础数值用于基础倍乘；普通数值修正不因行动被消费。只改某次行动的加值另计 | 仅基础层改 |
| 强化 | 下一次实际行动的前置加值；行动完成后消费，跳过不消费 | 不改 |
| 基础冷却／实际行动间隔／剩余冷却 | 基础冷却是卡牌秒数；热诚改变实际间隔，原进度保留；充能只减剩余秒数 | 热诚、充能均不改 |

### 晶体化与结晶

- **晶体化（迷宫专属）**：保留基础生命，额外最大生命与空白生命转为护甲。仅在攻击使护甲归零时，基础生命永久−1、基础护甲永久＋1。基础生命为1时原槽转为结晶，随战果保存。图标使用 2026-11-20 提供的 14×14 像素图。
- **结晶（迷宫专属）**：同时被视为造物，基础生命锁定为1。正向生命属性加成转为护甲，含基础生命与空白生命。治疗正常恢复生命，生命减益不扣甲，穿甲和溢出伤害可致死。图标使用原晶体化图标。

### 已确认的结算细节

摇曳青灯保留永久成长的持续范围，使用独立的最大生命差额。血誓之鞭只降低基础生命与上限。超星燃爆结束时，当前生命取当时与生效前的较小值，上限撤回本效果的增益，友军延迟五秒进入疲劳。
