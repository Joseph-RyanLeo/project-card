# D2-7 纹章检视与开发纹章库

本轮只加入准备阶段的开发用纹章目录与卡牌检视交互，不把审阅表中的纹章效果文案直接变成战斗效果。

## 当前实现

- PC 右键通过 `CardView → SquadView → BattlefieldRow → Main` 打开统一检视层；不再新增一套静态卡牌截图面板。
- 检视层使用固定逻辑画布：整卡在 SubViewport 内合成，通过 `InspectionCardSurface` 从原卡位置移动、放大到画面中心4倍，暗幕同步渐暗。复用卡面调整器的透视与扫光着色器；鼠标落点用同一逆投影公式换回卡面坐标。
- 纹章库复用收藏左侧的 `BadgePanel` 节点。检视时把同一个节点临时重挂到暗幕上层，关闭后恢复原父节点、位置、缩放与滚动状态。
- 空伤势／纹章槽中心显示 `2×2` 逻辑像素辅助点；点由 `CardView` 的状态槽绘制层生成，不写入 `OwnedCard`。
- 从库拖到点位后，调用 `OwnedCard.set_emblem_slot()` 写入纹章实例身份和定义 ID，现有 `capture_state()` 与 JSON 存档链路会保存该状态。
- 元素贴纸只接受符文槽，独立保存在 `OwnedCard.rune_stickers`；禁止覆盖另一枚贴纸，不改共享卡牌定义、底层符文或刮开状态。静态和闪耀素材使用用户提供的7枚27×27图案与14帧GIF，闪耀接入已有全局符文时间轴。
- 战斗阶段可以右键查看，但检视会暂停战斗；纹章库不可拖放，关闭后恢复原先的暂停状态。
- 常规库限制在124×248逻辑像素，检视库为86×120逻辑像素并放大4倍；滚动内容不撑大面板。刮刀固定在顶部工具位。原生拖拽采用独立预览根节点，图像保留实际抓取偏移，始终画在暗幕与卡牌之上。
- 检视标题栏提供显式“显示符文/显示描述”切换；长描述在卡牌侧边说明框中完整换行。收藏卡悬停 `0.25s` 后才切换描述，拖拽或叠卡预览开始会取消延迟并恢复符文显示。
- 检视卡两侧分别显示纹章工作包和伤势工作区，均为15px基础格、四列可滚动网格，并支持点击携带、长按拖动、合法落点预览及飞入动画；纹章和伤势只放各自槽位，元素贴纸只放符文槽。战斗与结算检视只读。
- 刮刀只在准备阶段松手且刀头命中时移除后贴纹章、伤势或符文贴纸；刮下后销毁，不返还工作包；卡牌原生符文仍不可移除。开发目录仍是无限定义来源，不是正式游戏免费奖励。旧存档已有的返还实例及实例序号继续保留，不因本次规则变化清除。
- 万能按已确认牌型优先级选择替代元素，同牌型按参与位置靠左优先；限制重复粘贴万能，旧存档中已有的返还实例仍计入持有。混沌贴上时随机普通元素；主界面已有按日标记去重的重抽方法，但完整日切流程尚未接入。混沌参与牌型时不再叠加倍率。
- 暗混沌纹章参与牌型后登记一次小队伤势治疗；候选池汇总小队每张随从卡上未被遮挡的非空伤势槽，结算时随机移除一处。若没有合法候选则不治疗。
- `data/emblem_wound_catalog.json` 是从审阅 CSV 规范导入的本地提示目录，含41条纹章与27条伤势；纹章/伤势卡面悬停显示规范描述、审阅状态和待确认项。它只是资料提示，不会自动启用未确认效果。
- 所有卡面持续绘制空伤势／纹章槽中心的2×2逻辑像素提示点；已占用槽隐藏提示点。提示由卡面内部统一绘制，因此收藏、战场、检视和快照共用实例布局，堆叠遮挡仍由上层卡牌覆盖。

## 定义与素材缺项

开发目录41条均已有图像：34张原纹章PNG，以及本轮补齐的7枚元素贴纸。目录悬停和已贴纹章/伤势的卡面提示读取本地导入的 CSV 规范描述、审阅状态和待确认项；这些是设计资料摘要，不会自动成为运行效果。当前审阅稿包含41条纹章与27条伤势。四叶草骰子、种子、免死等具体已确认规则见 `docs/CARD_CHARACTER_DESIGN.md`。

“天选之子”定义与素材文件“天选之人.png”名称不同，当前按同一已存在素材映射，不重复建立第二条纹章。

## Control 变换阻断修复

- 根因是 `EmblemLibraryView` 继承 `Panel/Control`，不能访问 Node2D 的 `global_scale` 与 `global_rotation`。现在在 `scripts/main.gd:3687` 保存 `get_global_transform_with_canvas()`，并通过 `_set_control_transform_from_canvas()` 将画布变换换算成新父节点下合法的 `position/scale/rotation`。
- 打开、正常关闭和立即关闭都复用同一份 `Transform2D` 快照；关闭后先恢复原父节点，再恢复原本地布局、尺寸、缩放、旋转、锚点支点、最小尺寸和滚动位置，避免 `set_inspect_mode(false)` 覆盖恢复值。
- 最小真实 SceneTree 烟雾验证命令：

  `Godot --headless --path . --script /private/tmp/project_card_inspection_control_transform_smoke.gd --log-file /private/tmp/project-card-inspection-control-transform-smoke.log`

  结果：打开、重挂、正常关闭、原父节点恢复、原位置恢复、立即关闭共 8 项 PASS，0 failures；日志无 `SCRIPT ERROR`、`Invalid access` 或 `global_scale/global_rotation` 访问错误。仅保留环境级 macOS 证书提示。
