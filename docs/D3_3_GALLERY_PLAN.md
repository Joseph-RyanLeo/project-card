## 目标与边界

从存档内大厅进入展览馆，浏览本档已发现的基础内容及保存的具体单卡。入口不放回启动主菜单。发现图鉴与三份实际收藏分开展示；已获得但未入藏的卡仍属于已发现。查看过程只读，不扣积分、不增加发现、不修改或删除收藏、不改变战绩。

D3-2已有的候选选择、替换二次确认及最终入藏继续在局后流程负责。D3-3不加入任务购买、完整任务树、教程路线、新卡效果或特殊对局带入；这些继续按原阶段规划实施。

## 按顺序实施

| 步骤 | 主要内容 | 完成条件 |
| --- | --- | --- |
| 1. 正式内容目录 | 扫描已有卡牌资源，核对主要卡包、正式／测试、启停、资源／衍生身份及生成源；建立可展示范围和发现总数 | 不把开发演示牌混入图鉴，不用停用状态代替正式身份；多包不重复计数 |
| 2. 卡牌收藏册 | 接通大厅入口与双页结构；每种一处基础图鉴位＋同排3个固定实例位；按主要卡包分组、品级降序 | 正确区分未知基础卡、已发现基础卡、空收藏位和真实收藏实例 |
| 3. 检视与查找 | 复用悬停透视、4倍只读检视、往返动画和黑体详情；按种族／类型筛选 | 实例外观、贴纸、成长、获得来源和累计战绩来自本档完整快照，不回写定义 |
| 4. 资源、贴纸与衍生 | 资源每行4种；纹章／伤势／元素贴纸独立区域；生成源打开衍生预览 | 未发现暗示和剪影不泄漏名称／效果；衍生预览不自动发现或创建收藏 |
| 5. 进度与回归 | 显示发现进度，完成三档隔离、旧档、返回与重启、720p／2K及大目录滚动检查 | 所有浏览操作前后档位数据一致，隐藏内容仍按规则进入总分母 |

每步先做可运行的小闭环再扩展，不在一次修改中堆出全部界面。

## 必须保留的已确认规则

- 未解锁卡包的分类与卡牌占位隐藏，已有发现记录保留。已解锁而未发现的卡只显示压暗背景、适用种族、行动方式及对应稀有度卡框；名称、立绘、效果与数值隐藏。多行动方式在左上图标轮换，无／不适用字段留空。
- 每种实际收藏的3个位置固定，不能手动换位或在展览馆删除。基础图鉴卡显示基础版本，实际收藏卡显示所保存的完整实例。
- 仅开发测试内容不收录、也不计发现总数。正式卡停用后，曾发现或收藏的保留展示，未发现的隐藏。未开放的正式内容仍计入发现进度分母。
- 未解锁的纹章、元素贴纸隐藏；开放而未发现的贴纸使用其原图剪影。伤势等已发现内容按实际发现数据展示，不为贴纸额外增加实例收藏位。
- 资源独立纯图鉴，每行4种，品级降序、同品级固定顺序，不配置实际单卡收藏位。发现条件沿用实际获得或玩家成功开采，单纯出现不算。
- 生成源被发现后即可查看其衍生卡，无须实际生成过。月露、齿轮废料等衍生资源保留生成源预览和资源图鉴双入口；预览不揭晓图鉴，不改变不计分／不入藏规则。

## 复用与数据职责

`ProfileProgress.profile.discoveries`提供本档永久发现，`profile.collection`提供已入藏实例，`profile.unlocks`提供显示资格。展览馆读取这些正式数据，不读取当前局的待提交发现，不另建第二份发现或收藏钱包。

`CardData`及现有目录提供基础内容，`OwnedCard`快照提供具体收藏；复用`CardView`、`CollectionCardHover`、`InspectionCardSurface`、现有检视关闭动画和UI字体。展览馆页面单独负责查询和排版，避免继续扩大`SlotHub`的局后职责；从大厅用信号进入／返回，存档写入仍由`GameDisplay`负责。

实现时优先缓存目录与复用可见卡位，让悬停继续共用一份高分辨率画布；不为所有图鉴卡持续开启独立渲染。`Resource`是共享定义，展示时应从实例快照读取状态，不能为了未知卡压暗或隐藏文字而改共享`CardData`。

## 开工时细化的界面与内容项

卡牌收藏册的双页、每侧三行和留白已获用户确认，分类、种族／类型筛选及按钮／PageUp／PageDown翻页已接通；同品级按稳定ID排序，卡包沿用定义中的主要归属。资源／贴纸沿用同尺寸双页，每侧三行、每行四种，生成源详情打开结果预览并可继续4倍检视。行动图标轮换时长仍是可调参数，不把它当作新玩法规则。

搜索可复用现有卡名／效果搜索作为查找补充，但未知内容不能因搜索结果泄漏隐藏文字。正式／测试内容身份要从现有资源及设计核对，不能简单把`is_available = false`全部当成开发牌或全部当成正式停用牌。存档缺少后补字段时保持原有兼容，不凭空补发现、解锁或历史战绩。

## 验证安排

先用真实资源验证目录去重、资格、排序、未知卡暗示、贴纸剪影及分母，再用隔离临时档验证大厅进入→筛选／滚动→卡牌检视→资源／贴纸切换→衍生预览→返回大厅→独立进程恢复。覆盖新档、不同解锁档、已有收藏、正式停用记录和三档隔离。

图形检查覆盖720p／2K、长名称／长战绩、空列表、大目录滚动、连续进出检视及关闭清理；浏览前后比较真实存档，确认只读。Godot进程串行并显式指定临时日志，不用开发档直接改数据的方式冒充正式解锁流程；完整任务购买／解锁链仍在D3-4及后续闭环验证。
