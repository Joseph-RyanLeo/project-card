# Project Card Visual References

本文保存 Project Card 当前已确认的视觉参考图。图片来自前期 QQ 讨论记录，已复制到项目内的稳定路径，后续不再依赖 QQ 缓存目录。

## 图 1：随从卡完整卡面

![随从卡完整卡面](images/card-minion-full.png)

用于说明：

- 卡面插画区域。
- 行动方式与数值位置。
- 生命值与护甲位置。
- 元素符文区域。
- 种族标识位置。
- 伤势与强化槽位的边缘分布方向。

## 图 2：卡牌效果与符文显示切换

![卡牌效果与符文显示切换](images/card-effect-toggle.png)

用于说明：

- 鼠标悬停或右键切换后，卡牌下方区域可在效果文本与元素符文之间切换。
- 卡牌效果文本区域需要支持简短描述。
- 元素符文显示区域需要清晰展示多个符文。

## 图 6：两张卡牌堆叠示例

![两张卡牌堆叠示例](images/card-stack-2.png)

用于说明：

- 两张卡牌堆叠后形成小队。
- 被遮挡区域不再生效。
- 未被遮挡的元素符文按从左到右形成牌型。
- 卡牌本体保持实际堆叠表现。
- 元素符文与效果区域会整合为一个整体。

## 图 7：三张卡牌堆叠示例

![三张卡牌堆叠示例](images/card-stack-3.png)

用于说明：

- 三张卡牌堆叠后的最大复杂度。
- 可见元素符文和遮挡关系。
- 多卡堆叠时整体占位、吸附和表现格式。

## 图 8：牌型与元素效果配置表

![牌型与元素效果配置表](images/combo-config-table.png)

用于说明：

- 基础数值暂定为 10。
- 牌型倍率目前包含对子、三条、葫芦、两对。
- 元素倍率目前包含火、水、暗、木、光。
- 顺子和同花的倍率及效果仍待补充。
