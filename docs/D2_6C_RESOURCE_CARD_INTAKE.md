# D2-6C 资源卡与开采资料接入

玩法权威仍是 `GAMEPLAY_DESIGN.md`。本文件记录本次提前接入的卡牌资料，不把尚未确认的开采结算伪装成已完成机制。

## 已录入卡牌

- `矿稿`：迷宫卡包，I级近战武器；基础数值+1，生命、护甲、热诚均为+0；关键词为开采，`开采1。`表示每场战斗一次。
- `火元素碎晶`：II级矿物，生命2；收获时数值永久+1。
- `光元素碎晶`：II级矿物，生命2；收获时获得2金币。
- `暗元素碎晶`：II级矿物，生命2；收获时永久治疗一处伤势。
- `水元素碎晶`：II级矿物，生命2；收获时生命永久+2。
- `木元素碎晶`：II级矿物，生命2；收获时护甲永久+1。
- `彩金矿`：III级矿物，生命7；收获时获得1金币并投2d10，额外奖励按最高档不叠加。
- `晶化残躯`：II级矿物，生命6；收获时按1d10结果获得元素碎晶或纹章。
- `贪欲之石`：I级矿物，生命3；收获时按1d10失去或获得金币。
- `废弃工具箱`：I级遗物，生命2；收获时随机获得一件I级装备。

本次卡牌资料使用 `CardData` 的资源卡字段和 `effect_text` 保存。资源卡没有擅自加入主场景初始收藏，也没有伪造立绘素材或开采效果 ID。

## 明确未实现与待确认

- 资源卡是否占用棋盘栏位、普通攻击与范围效果如何选择资源卡、开采目标如何优先、开采成功时点、奖励归属和随机池仍属于 D2-6C 机制范围。
- 彩金矿的 `2d10` 额外奖励按用户原文保存为最高档生效：`>15` 为5金币、`>18` 为10金币、`=20` 为20金币，不叠加。
- 贪欲之石规则已确认：掷出10时，整次效果只获得10金币，不同时执行“>5获得3金币”或“<6失去2金币”；`=10` 为最高优先级的独立分支。
- 本批卡牌没有用户提供的正式立绘素材；卡面资源先以无立绘的可加载数据接入，不能视为美术完成。
