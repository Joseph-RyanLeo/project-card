# D2-6C 资源卡与开采资料接入

通用玩法入口为 `GAMEPLAY_DESIGN.md`，具体资源卡设定见 `docs/CARD_CHARACTER_DESIGN.md`。本文件记录资源卡资料、素材与规则确认；资源战斗、开采与收获实现状态见 `docs/D2_6C_IMPLEMENTATION.md`。

## 已录入卡牌

- `矿镐`：迷宫卡包，I级近战武器；基础数值+1，生命、护甲、热诚均为+0；关键词为开采，`开采1。`表示每场战斗一次。
- `火元素碎晶`：II级矿物，生命2；收获时数值永久+1。
- `光元素碎晶`：II级矿物，生命2；收获时获得2金币。
- `暗元素碎晶`：II级矿物，生命2；收获时永久治疗一处伤势。
- `水元素碎晶`：II级矿物，生命2；收获时生命永久+2。
- `木元素碎晶`：II级矿物，生命2；收获时护甲永久+1。
- `彩金矿`：III级矿物，生命7；收获时获得1金币并投2d10，额外奖励按最高档不叠加。
- `晶化残躯`：II级矿物，生命6；收获时按1d10结果获得元素碎晶或纹章。
- `贪欲之石`：I级矿物，生命3；收获时按1d10失去或获得金币。
- `废弃工具箱`：I级遗物，生命2；收获时随机获得一件I级装备。

本次卡牌资料使用 `CardData` 的资源卡字段和 `effect_text` 保存。资源卡定义不因此全部加入初始收藏；关卡自动抽取只使用现存I—III级资源池。矿镐沿用既有定义、id、初始收藏与调试器入口。开采钩子现在由 BattleController 正式消费，不再是延后占位。

## 已确认规则与实现边界

- 资源区域独立于棋盘栏位；普通攻击、开采、结算、奖励与随机池按 `docs/D2_6C_IMPLEMENTATION.md` 中确认规则执行。
- 彩金矿的 `2d10` 额外奖励按用户原文保存为最高档生效：`>15` 为5金币、`>18` 为10金币、`=20` 为20金币，不叠加。
- 贪欲之石规则已确认：掷出10时，整次效果只获得10金币，不同时执行“>5获得3金币”或“<6失去2金币”；`=10` 为最高优先级的独立分支。
- 本批卡牌已提供正式立绘源文件并复制至 `assets/card_art/resources/`；按每张原图尺寸导入，CardData 使用既有裁切窗口与 `art_offset`，不统一拉伸。
