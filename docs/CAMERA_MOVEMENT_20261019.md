# 视角移动364像素与回弹

## 整体流程

点击人物或流程切换调用`main.gd`的`set_world_view()`。上半视角原点为(0,3)，下半为(-1,367)，实际垂直距离364像素；此前距离365像素，所以新下半视角向上观察1像素。世界父节点的位置取原点的负值，因此画面中的素材向下移动1像素。

动画先沿移动方向越过目标6像素，再回到准确终点。转向下半时世界从Y=-3移到-373、回到-367；返回上半时移到Y=3、回到-3。快速反向会取消旧Tween并从当前显示位置开始，不跳回原起点。

## 关键脚本与参数

- `scripts/main.gd`：`VIEW_VERTICAL_TRAVEL=364`控制实际垂直距离，`VIEW_OVERSHOOT_PIXELS=6`控制越位幅度，`VIEW_TWEEN_DURATION=0.32`和`VIEW_SETTLE_DURATION=0.12`控制前进与回弹时长，总计0.44秒。
- `set_world_view()`继续只移动`WorldContent`；`animate=false`精确立即定位，相同视角已到达时不再弹动。
- `scripts/ui/maze_run_hud.gd`：英雄板直接使用固定世界位置(1084,749)，不依赖摄像机原点生成布局。因此与其他素材一起接受同一视角变化，下半屏幕位置从(1085,381)变为(1085,382)。

## Godot写法

Tween按添加顺序播放两段`tween_property()`，不使用循环。第一段二次缓出在越位处减速，第二段正弦缓入缓出收回；`signf()`根据目标与当前位置的Y差确定越位方向，上下共用同一套逻辑。世界位置是视角原点的负值，所以摄像机向下时素材向上。
