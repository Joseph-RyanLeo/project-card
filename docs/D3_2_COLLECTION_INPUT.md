## 整体流程

候选改为每行5张的连续滚动网格，没有上一页／下一页和逐卡“检视／选择”按钮。鼠标悬停时卡牌跟随指向产生检视透视倾斜；左键卡面立即选择／取消，选中后两束像素光沿卡边循环。满8张后不再新增假选中状态。普通空位直接选择，已满3位则打开原有新旧对比与替换二次确认，预览不提前移除旧收藏。

右键卡面先从原位动画过渡到逻辑4倍，再逐行显现右侧信息；背景为变暗蒙版。右侧“卡牌详情 / 积分构成”页签分别展示效果、实例与历史，以及正式计分组成、本局倍率，正文统一使用项目中文黑体。“卡面／效果”按钮已从此界面移除。再次右键、Esc或关闭按钮以0.22秒动画将大卡缩回原位、整体渐隐后关闭；期间继续拦截输入，Esc只关闭当前大卡，不返回主菜单。集合预览只读，需要修改时返回选卡。

后续同日修正增加右上角品级、行动方式与卡名／效果搜索，选中金光与卡面一起透视。完整八项反馈、实现讲解与最新验证见[卡牌交互与收藏检视修正](CARD_FEEDBACK_REVISION_20261102.md)。

最新替换比较已改为随显示壳缩放的全画布覆盖层，四张卡在720p／2K均保持逻辑2倍；移除翻面按钮，效果直接列在卡下。图片总结与精细文字说明见[可读性修正](UI_READABILITY_REVIEW_20261102.md)。

原候选确实采用1.12倍局部缩放，随后又被1280×720逻辑画布按窗口尺寸缩放，导致像素宽度不均。现在静止卡为原生99×136逻辑1倍、整数位置，替换对比卡为整数2倍；倾斜层使用至少4倍合成精度并保持最近邻原画采样。**1倍／4倍指逻辑画布倍率**：720p窗口为实际1倍／4倍，2K窗口整体2倍时为实际2倍／8倍。原1080p或任意尺寸全屏的非整数整体缩放仍沿用用户显示设置，没有静默改变全局窗口模式。

## 数据与脚本职责

- `scripts/ui/slot_hub.gd`：ScrollContainer与GridContainer负责连续浏览；`_choose_card()`直接点选或打开必要的替换比较；`_inspect()`复用CardInspectionOverlay和InspectionCardSurface组成大卡与右侧详情。候选身份列表不变时，只同步选择状态，不重新实例化90张卡，也不重置滚动位置。
- `scripts/ui/collection_candidate_card.gd`：每个卡位保留一个只读CardView、一个卡面输入区和一条收藏数量说明。输入区转发左键／右键，滚轮留给父滚动区。金光由卡面子节点`card_selection_halo.gd`绘制，已选时才更新，并同步到倾斜合成卡面。
- `scripts/ui/collection_card_hover.gd`：复用已有单份高分辨率倾斜层，新增只读输入方式。卡位从真实鼠标事件传入归一化坐标；不启用局内拖放，不消除候选新卡标记，不修改OwnedCard。移开、滚动、打开大卡或离开页面时回收显示层并恢复原卡。
- `scripts/ui/game_display.gd`：选择沿用原存档事务；保存失败不显示假选中标记。Esc优先关闭大卡。原积分、候选、替换与集合数据结构没有改变。

## 初学者需要留意的写法

`CardView.set_snapshot_mode(true)`用于只读显示，也会关闭自身鼠标输入。因此另设卡面大小的Control接收点击和鼠标移动，卡面保持只读，二者不会混用拖拽逻辑。

悬停只让当前一张卡借用共享InspectionCardSurface；90张静态卡不会各自创建一个持续渲染的SubViewport。归一化坐标把卡面中心换成(0,0)、四角换成(-1,-1)至(1,1)，再复用现有平滑和着色器，真实输入与自动验证一致。

ScrollContainer负责裁剪和滚轮，GridContainer负责排列。选择动作不释放网格节点，避免滚动中选卡突然回顶部；只更新标签、选中状态及绘制开关。环绕效果用`_draw()`画像素尾迹，只有最多8张已选卡持续更新。
