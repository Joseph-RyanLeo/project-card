# D2-6B 法术准备与释放闭环实施计划

## 本阶段目标

把收藏中的法术实例按顺序放入我方准备栏，写入战前快照并随本局存档恢复；开战后按即时、条件、准备类别及法术顺序调度，并完成四张正式法术的效果、演出协调与战后耐久结算。

## 实施步骤

1. 盘点现有准备栏、战斗事件队列、效果运行时和战前/磁盘存档入口；补齐准备实例顺序、容量校验、去重与恢复。
2. 建立可取消的开场阶段与法术串行队列，保证开场战斗时间保持 0，普通战斗时间与条件法术演出并行；区分战斗阶段、手动暂停、检视暂停和特殊法术暂停。
3. 接入 `side_by_side`、`battle_fury`、`volley_order`、`return_to_battlefield` 的正式触发和效果逻辑；复用现有战斗状态、效果、弹道与命中入口。
4. 把准备法术纳入战后一次性耐久结算，并验证未完成战斗快照恢复及重复提交。
5. 增补真实对象/场景测试，更新规则详则与阶段交接文档，记录已验证和未验证边界。

## 验收重点

- 准备栏左侧分列、同类顺序可持久化，收藏仍保有同一实例；容量默认 10，英雄容量通过单一配置入口扩展到 20。
- 即时法术开场依序演出与结算，计时严格为 0；弹道命中和逻辑顺序不依赖 UI 帧回调。
- 准备法术各自只在第 8/15 秒尝试一次；条件法术在正确事件触发后串行插入，免死在伤害写入前生效。
- 视觉暂停仅由对应持有者释放；重开/退出清理旧代次演出和暂停状态。
- 本场准备的法术无论是否触发只在正常结算时扣一次耐久；战斗中断恢复快照后不扣耐久。
